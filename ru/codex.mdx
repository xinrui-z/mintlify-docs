</Note>

## 1. Получите API-ключ

Откройте [консоль Harogo](https://console.harogo.ai/keys), создайте API-ключ и скопируйте его. Считайте ключ паролем. Не добавляйте его в репозиторий и не передавайте другим. Выберите [ключ подписки или ключ баланса](/ru/pricing#billing-keys) в зависимости от способа оплаты.

## 2. Настройте Harogo

Добавьте провайдер Harogo в существующий `~/.codex/config.toml`. Сохраните текущие провайдеры и профили; не заменяйте весь файл.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Указывайте `profile = "harogo"` только если Harogo должен быть профилем по умолчанию. В существующем `~/.codex/auth.json` обновите только значение `OPENAI_API_KEY`, сохранив остальные записи.

При использовании [CC Switch](/ru/troubleshooting#cc-switch) добавьте и включите там тот же провайдер вместо этого. Не объединяйте конфигурации, если не знаете, какая из них имеет приоритет.

Перед выбором ID модели проверьте [таблицу совместимости моделей](/ru#model-compatibility).

## 3. Проверьте подключение

Запустите уже установленный клиент из каталога проекта:

```shellscript
codex
```

Отправьте короткий запрос, например `Reply with exactly: 2`. Проверьте ответ и активную модель, например `gpt-6.2-sol`. Обычный ответ сам по себе не подтверждает, что активен Harogo.
