<Note>
**В этом руководстве используются только модели GPT.** Codex может запускать модели GPT (GPT-6 Luna, GPT-6 Sol, GPT-6.1 Sol, GPT-6 Astra, GPT-6.1 Terra) и модели без ограничений по клиенту (GLM, Qwen, Kimi, MiniMax, DeepSeek). Модели Claude в Codex недоступны — см. [Claude Code](/ru/claude-code).
</Note>

## Установка

### Загрузка с официального сайта (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Установка через командную строку

```bash
npm install -g @openai/codex
```

## Настройка переменных окружения

### Настройка через файл конфигурации

1. Откройте файл `~/.codex/config.toml` и добавьте в него следующее:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Откройте файл `~/.codex/auth.json` и измените его следующим образом:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Работа с Codex

### В терминале

1. Откройте терминал, перейдите в каталог проекта и выполните команду `codex`.

```bash
cd /path/to/your/project
codex
```

2. Настройте разрешения по необходимости.

<img
  alt="Настройка разрешений на подтверждение при запуске Codex"
  width="1212"
  height="814"
  data-path="public/cn/codex-5.png"
  lightAlt="Настройка разрешений на подтверждение при запуске Codex"
  darkAlt="Настройка разрешений на подтверждение при запуске Codex"
  src="/images/iShot_2026-08-07_17.31.13.png"
/>

3. Введите запрос на естественном языке: если пришёл нормальный ответ, настройка выполнена успешно.
