# Введение

Harogo — мультимодельная подписка, созданная для кодинг-агентов.

Подписка по сниженной цене стоит \$4.90 за первый месяц, затем \$9.90/месяц; сейчас доступно 100 мест по сниженной цене. Оставшиеся места и итоговая цена указаны на странице подписки. Подписка автоматически продлевается каждый месяц, оплата списывается с вашей карты через Stripe. Цена первого месяца действует только для вашей первой подписки Harogo. Отменить автопродление можно в любой момент на странице **Plan** в консоли; доступ сохраняется до конца уже оплаченного периода.

После оформления подписки вы можете использовать несколько моделей для разработки через один аккаунт Harogo и один API-ключ. Все модели расходуют одну общую квоту подписки, поэтому не нужно регистрироваться, пополнять баланс и управлять отдельными платформами моделей.

# Почему Harogo

Разные модели хорошо справляются с разными задачами по разработке. Использование нескольких провайдеров моделей напрямую обычно означает управление несколькими аккаунтами, API-ключами, балансами, лимитами запросов и счетами одновременно.

Harogo объединяет в одном сервисе набор моделей, хорошо подходящих для кодинг-агентов. Вы свободно переключаете модели под задачу, а всё использование списывается с одной общей квоты подписки.

Текущие модели условно делятся на следующие группы:

- **Крупные кодовые базы и сложные рассуждения**: Kimi K3.1 Pro, Claude Opus 5.5, GPT-6.2 Sol, GPT-6.2 Astra
- **Повседневное агентное программирование, генерация кода и отладка**: Qwen4 Max, GLM-5.4, GLM-5.3, Claude Sonnet 5.5, GPT-6.1 Terra, MiniMax M3, DeepSeek V4 Pro
- **Высокочастотные вызовы, быстрые ответы и задачи с чувствительностью к стоимости**: DeepSeek V4.1 Flash 1017, Claude Haiku 5.5, GPT-6 Luna

Эти группы — лишь ориентир при выборе модели. Реальный результат зависит от задачи, контекста и способа использования инструментов.

# Начало работы

1. Войдите в Harogo и оформите подписку.
2. Создайте и скопируйте API-ключ в консоли.
3. Используйте `https://api.harogo.ai` для [Claude Code](/ru/claude-code) или `https://api.harogo.ai/v1` для [Codex](/ru/codex) и [OpenCode](/ru/opencode). Следуйте руководству для своего клиента.
4. Вставьте свой API-ключ.
5. Можно начинать работу.

Храните API-ключ в секрете: не коммитьте его в публичный репозиторий и никому не передавайте.

## Доступность моделей по клиентам

Часть моделей доступна только в определённом клиенте. Остальные модели используются где угодно.

<Note>
**Модели GPT** (GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra) доступны только в [Codex](/ru/codex).

**Модели Claude** (Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5) доступны только в [Claude Code](/ru/claude-code).

**Все остальные модели** (GLM, Qwen, Kimi, MiniMax, DeepSeek) не имеют ограничений по клиенту и работают в любом поддерживаемом клиенте.
</Note>

## Использование и лимиты

В Harogo действуют следующие лимиты использования:

- Дневной лимит: \$12
- Недельный лимит: \$30
- Месячный лимит: \$60

Все три лимита действуют одновременно. Каждый вызов модели расходует общую квоту подписки. У каждой модели свой лимит использования: модели с лимитом ниже \$60 расходуют общую квоту быстрее, а модели с лимитом выше \$60 — медленнее. Лимиты моделей приведены на странице [Цены](/ru/pricing).

Лимиты заданы в долларовом эквиваленте, а не фиксированным числом запросов. Сколько запросов вы реально получите, зависит от модели: более дешёвые модели обычно дают больше запросов, более дорогие — меньше.

Текущее использование и остаток квоты можно посмотреть в [консоли Harogo](https://console.harogo.ai/plan).

### Оценочный объём запросов

В таблице ниже приведена оценка числа запросов для каждой модели на основе типичных сценариев использования Harogo. Общая квота составляет \$12 / \$30 / \$60 в день / неделю / месяц, но у каждой модели свой лимит использования: модель с более низким лимитом расходует общую квоту быстрее. Указанный лимит — это сколько может использовать одна эта модель в каждом окне.

<Note>
**Лимиты использования — это не отдельные квоты.** Все модели расходуют одну общую квоту: \$12 в день, \$30 в неделю и \$60 в месяц. Лимит модели показывает лишь, сколько можно использовать, если работать только с этой моделью: лимиты не суммируются, и за одно и то же окно нельзя исчерпать полный лимит каждой модели. Например, если полностью израсходовать месячный лимит Kimi K3.1 Pro в \$15, вся общая квота на месяц будет исчерпана и для других моделей ничего не останется.
</Note>
