Harogo — мультимодельная подписка, созданная для кодинг-агентов.

После оформления подписки вы можете использовать несколько моделей для разработки через один аккаунт Harogo и один API-ключ. Все модели расходуют одну общую квоту подписки, поэтому не нужно регистрироваться, пополнять баланс и управлять отдельными платформами моделей.

## Начало работы

1. [Откройте страницу подписки Harogo](https://console.harogo.ai/plan)
2. [Создайте и скопируйте ключ API в консоли](https://console.harogo.ai/keys)
3. Следуйте инструкции для вашего клиента: [Claude Code](/ru/claude-code) или [Codex](/ru/codex).

Храните API-ключ в секрете: не коммитьте его в публичный репозиторий и никому не передавайте.

## Поддерживаемые модели {#model-compatibility}

Эти результаты относятся к базовому тарифу Harogo. [Claude Code](/ru/claude-code) использует `POST /v1/messages`, а [Codex](/ru/codex) — `POST /v1/responses`.

| Модель | ID модели | Для чего подходит | Messages | Responses |
| --- | --- | --- | --- | --- |
| GLM-5.4 | `glm-5.4` | Долгие задачи, крупные кодовые базы, агентное программирование | Недоступно | Поддерживается |
| Qwen4 Max | `qwen4-max` | Сложные рассуждения, понимание изображений и встроенный вызов инструментов | Недоступно | Поддерживается |
| Kimi K3.1 Pro | `kimi-k3.1-pro` | Долгие задачи программирования, контекст 1M, фронтенд и 3D-моделирование | Недоступно | Поддерживается |
| MiniMax M3 | `minimax-m3` | Высокочастотное программирование, вызовы инструментов, длинный контекст | Недоступно | Поддерживается |
| DeepSeek V4 Pro | `deepseek-v4-pro` | Рассуждения и сложная генерация кода | Недоступно | Поддерживается |
| DeepSeek V4.1 Flash 1017 | `deepseek-v4.1-flash-1017` | Быстрые ответы, высокочастотные вызовы, пакетные задачи | Недоступно | Поддерживается |
| Claude Opus 5.5 | `claude-opus-5-5` | Сложное агентное программирование и трудные инженерные задачи | Разрешены только запросы из Claude Code | Недоступно |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | Повседневное программирование и общие задачи разработки | Разрешены только запросы из Claude Code | Недоступно |
| Claude Haiku 5.5 | `claude-haiku-5-5` | Быстрые ответы, лёгкие задачи, пакетная обработка | Разрешены только запросы из Claude Code | Недоступно |
| GPT-6 Luna | `gpt-6-luna` | Высокочастотное программирование и лёгкие задачи | Недоступно | Поддерживается |
| GPT-6.2 Sol | `gpt-6.2-sol` | Сложная генерация кода, ревью и рассуждения | Недоступно | Поддерживается |
| GPT-6.2 Astra | `gpt-6.2-astra` | Флагманское рассуждение для самых сложных инженерных задач | Недоступно | Поддерживается |
| GPT-6.1 Terra | `gpt-6.1-terra` | Повседневное агентное программирование и общие задачи | Недоступно | Поддерживается |

Названия и ID моделей выше — это идентификаторы маршрутизации, которые Harogo использует внутри сервиса. Состав моделей, версии и доступность могут меняться — актуальный список смотрите в консоли.
