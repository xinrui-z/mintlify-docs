# Введение

Harogo — мультимодельная подписка, созданная для кодинг-агентов.

Подписка по сниженной цене стоит \$4.90 за первый месяц, затем \$9.90/месяц; сейчас доступно 100 мест по сниженной цене. Оставшиеся места и итоговая цена указаны на странице подписки.

После оформления подписки вы можете использовать несколько моделей для разработки через один аккаунт Harogo и один API-ключ. Все модели расходуют одну общую квоту подписки, поэтому не нужно регистрироваться, пополнять баланс и управлять отдельными платформами моделей.

# Почему Harogo

Разные модели хорошо справляются с разными задачами по разработке. Использование нескольких провайдеров моделей напрямую обычно означает управление несколькими аккаунтами, API-ключами, балансами, лимитами запросов и счетами одновременно.

Harogo объединяет в одном сервисе набор моделей, хорошо подходящих для кодинг-агентов. Вы свободно переключаете модели под задачу, а всё использование списывается с одной общей квоты подписки.

Текущие модели условно делятся на следующие группы:

- **Крупные кодовые базы и сложные рассуждения**: Kimi K3.1 Pro, Claude Opus 5.5, GPT-6.1 Sol, GPT-6 Sol, GPT-6 Astra
- **Повседневное агентное программирование, генерация кода и отладка**: Qwen3.8 Max, GLM-5.3, Claude Sonnet 5.5, Claude Sonnet 5, GPT-6.1 Terra, MiniMax M3, DeepSeek V4 Pro
- **Высокочастотные вызовы, быстрые ответы и задачи с чувствительностью к стоимости**: DeepSeek V4.1 Flash 1017, Claude Haiku 5.5, GPT-6 Luna
- **Продолжительные многошаговые агентные рабочие процессы**: Claude Fable 5.1

Эти группы — лишь ориентир при выборе модели. Реальный результат зависит от задачи, контекста и способа использования инструментов.

# Начало работы

1. Войдите в Harogo и оформите подписку.
2. Создайте и скопируйте API-ключ в консоли.
3. Укажите Base URL `https://harogo.ai`.
4. Вставьте свой API-ключ.
5. Можно начинать работу.

Храните API-ключ в секрете: не коммитьте его в публичный репозиторий и никому не передавайте.

## Использование и лимиты

В Harogo действуют следующие лимиты использования:

- Дневной лимит: \$12
- Недельный лимит: \$30
- Месячный лимит: \$60

Все три лимита действуют одновременно. Каждый вызов модели расходует общую квоту подписки. У DeepSeek V4 Pro лимит квоты составляет \$15, у всех остальных моделей — \$60.

Лимиты заданы в долларовом эквиваленте, а не фиксированным числом запросов. Сколько запросов вы реально получите, зависит от модели: более дешёвые модели обычно дают больше запросов, более дорогие — меньше.

Текущее использование и остаток квоты можно посмотреть в [консоли Harogo](https://console.harogo.ai/plan).

Для новых версий моделей пока используется профиль запросов, наблюдавшийся у их предшественников. Число запросов = квота окна ÷ (прайсовая цена одного запроса × 0.1); для моделей с лимитом квоты \$15 результат масштабируется коэффициентом \$15 / \$60.

Эти цифры служат для оценки типичного использования и не являются обязательством предоставить какое-либо фиксированное число запросов. Лимиты квоты и оценочный объём запросов могут меняться по мере развития сервиса — актуальную информацию смотрите в консоли Harogo и на этой странице.
