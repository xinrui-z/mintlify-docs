Перед установкой убедитесь, что система соответствует следующим требованиям:

- **Node.js ≥ 18.0.0**
- Менеджер пакетов для вашей платформы (необязательно):
  - macOS / Linux: `brew`
  - Arch Linux: `paru`
  - Windows: `choco`, `winget` или `scoop`

## 1. Установка OpenCode

Выберите способ установки, который подходит вашей системе и инструментам.

### 1. Установка через Node.js

```text
# Быстрая установка через скрипт curl
curl -fsSL https://opencode.ai/install | bash

# Через NPM
npm install -g opencode-ai

# Через Bun
bun install -g opencode-ai

# Через PNPM
pnpm install -g opencode-ai

# Через Yarn
yarn global add opencode-ai
```

---

### 2. Через Homebrew (macOS / Linux)

```text
brew install sst/tap/opencode
```

---

### 3. Через Paru (Arch Linux)

```text
paru -S opencode-bin
```

---

### 4. Установка в Windows

В Windows OpenCode можно установить любым из следующих способов:

```text
# Chocolatey
choco install opencode

# WinGet
winget install opencode

# Scoop
scoop bucket add extras
scoop install extras/opencode

# Или через NPM (нужен Node.js); требуются права администратора
npm install -g opencode-ai
```
