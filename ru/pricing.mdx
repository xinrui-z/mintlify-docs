## Примечания

- Месячный лимит зависит от модели. Модели с более низким лимитом расходуют общую квоту быстрее, с более высоким — медленнее.
- Лимиты использования — это не отдельные квоты: все модели делят одну квоту, а каждый лимит показывает лишь, сколько может использовать одна эта модель. Лимиты не суммируются.
- Для моделей с диапазоном ввода действует ступенчатая цена: если общий ввод одного запроса (ввод + чтение кэша + запись в кэш) превышает порог, весь запрос тарифицируется по более высокой ступени.
- Стоимость использования API рассчитывается по ценам из таблицы. Множитель модели определяет, сколько списывается из общей квоты подписки.
- При оплате с баланса аккаунта, а не из квоты подписки, списываются полные цены из таблицы.

Цены и лимиты могут меняться вместе с составом моделей. Источник актуальных данных — [консоль Harogo](https://console.harogo.ai/plan) и эта страница.

## Использование и лимиты {#usage-limits}

В Harogo действуют следующие лимиты использования:

- Дневной лимит: \$12 (сбрасывается ежедневно в **16:00 UTC**)
- Недельный лимит: \$30 (сбрасывается каждые 7 дней с момента первого использования подписки)
- Месячный лимит: \$60 (сбрасывается каждые 30 дней с момента первого использования подписки)

Все три лимита действуют одновременно. У каждой модели свой лимит использования: модели с лимитом ниже \$60 расходуют общую квоту быстрее, а модели с лимитом выше \$60 — медленнее. Лимиты моделей приведены на странице [Цены](#token-prices).

Лимиты заданы в долларовом эквиваленте, а не фиксированным числом запросов. Сколько запросов вы реально получите, зависит от модели: более дешёвые модели обычно дают больше запросов, более дорогие — меньше.

Текущее использование и остаток квоты можно посмотреть в [консоли Harogo](https://console.harogo.ai/plan).

### API-ключи для подписки и баланса {#billing-keys}

Создайте отдельные ключи на [странице API-ключей](https://console.harogo.ai/keys): ключ подписки для расходования квоты тарифа и ключ баланса для оплаты со счёта. Использование учитывается отдельно. При исчерпании квоты подписки Harogo не списывает средства с баланса автоматически.
