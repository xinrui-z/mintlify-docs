<Note>
Op deze pagina gaan we ervan uit dat Codex CLI al is geïnstalleerd.
</Note>

## 1. Een API-key ophalen

Open de [Harogo-console](https://console.harogo.ai/keys), maak een API-key aan en kopieer deze. Behandel de key als een wachtwoord. Commit of deel de key niet. Kies een [abonnements- of tegoedsleutel](/nl/pricing#billing-keys), afhankelijk van hoe je wilt betalen.

## 2. Harogo configureren

Voeg de Harogo-provider toe aan je bestaande `~/.codex/config.toml`. Behoud bestaande providers en profielen; vervang niet het hele bestand.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Stel `profile = "harogo"` alleen in als Harogo het standaardprofiel moet zijn. Werk in het bestaande `~/.codex/auth.json` alleen de waarde van `OPENAI_API_KEY` bij en behoud alle andere items.

Gebruik je [CC Switch](/nl/troubleshooting#cc-switch), voeg daar dan in plaats daarvan dezelfde provider toe en activeer deze. Combineer configuraties niet als je niet weet welke voorrang heeft.

Bekijk de [tabel met modelcompatibiliteit](/nl#model-compatibility) voordat je een model-ID kiest.

## 3. De verbinding controleren

Start de al geïnstalleerde client vanuit je projectmap:

```shellscript
codex
```

Stuur een minimale opdracht zoals `Reply with exactly: 2`. Controleer de reactie en het actieve model, bijvoorbeeld `gpt-6.2-sol`. Een normale reactie bewijst op zichzelf niet dat Harogo actief is.
