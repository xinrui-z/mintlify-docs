## Installatie

### Downloaden van de officiële website (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Installeren via de opdrachtregel

```bash
npm install -g @openai/codex
```

## Omgevingsvariabelen configureren

### Configureren via het configuratiebestand

1. Bewerk je bestand `~/.codex/config.toml` en voeg het volgende toe:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Bewerk je bestand `~/.codex/auth.json` en pas het als volgt aan:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Codex gebruiken

### In de terminal

1. Open een terminal, ga naar je projectmap en voer de opdracht `codex` uit.

```bash
cd /path/to/your/project
codex
```

2. Stel de rechten naar wens in.

<img
  alt="Goedkeuringsrechten instellen bij het starten van Codex"
