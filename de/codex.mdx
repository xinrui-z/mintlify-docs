## Installation

### Download von der offiziellen Website (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Installation über die Kommandozeile

```bash
npm install -g @openai/codex
```

## Konfiguration der Umgebungsvariablen

### Konfiguration über die Konfigurationsdatei

1. Bearbeiten Sie Ihre Datei `~/.codex/config.toml` und fügen Sie Folgendes hinzu:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Bearbeiten Sie Ihre Datei `~/.codex/auth.json` und passen Sie sie wie folgt an:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Codex verwenden

### Im Terminal

1. Öffnen Sie ein Terminal, wechseln Sie in Ihr Projektverzeichnis und führen Sie den Befehl `codex` aus.

```bash
cd /path/to/your/project
codex
```

2. Legen Sie die Berechtigungen nach Bedarf fest.

<img
  alt="Festlegen der Freigabeberechtigungen beim Start von Codex"
  width="1212"
  height="814"
  data-path="public/cn/codex-5.png"
  lightAlt="Festlegen der Freigabeberechtigungen beim Start von Codex"
  darkAlt="Festlegen der Freigabeberechtigungen beim Start von Codex"
  src="/images/iShot_2026-08-07_17.31.13.png"
/>

3. Geben Sie einen Prompt in natürlicher Sprache ein. Wenn Sie eine normale Antwort erhalten, war die Einrichtung erfolgreich.
