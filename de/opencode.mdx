Stellen Sie vor der Installation sicher, dass Ihr System die folgenden Voraussetzungen erfüllt:

- **Node.js ≥ 18.0.0**
- Ein Paketmanager für Ihre Plattform (optional):
  - macOS / Linux: `brew`
  - Arch Linux: `paru`
  - Windows: `choco`, `winget` oder `scoop`

## 1. OpenCode installieren

Wählen Sie die Installationsmethode, die zu Ihrem System und Ihren Tools passt.

### 1. Installation über Node.js

```text
# Schnellinstallation per curl-Skript
curl -fsSL https://opencode.ai/install | bash

# Mit NPM
npm install -g opencode-ai

# Mit Bun
bun install -g opencode-ai

# Mit PNPM
pnpm install -g opencode-ai

# Mit Yarn
yarn global add opencode-ai
```

---

### 2. Mit Homebrew (macOS / Linux)

```text
brew install sst/tap/opencode
```

---

### 3. Mit Paru (Arch Linux)

```text
paru -S opencode-bin
```

---

### 4. Installation unter Windows

Unter Windows können Sie OpenCode auf eine der folgenden Arten installieren:

```text
# Chocolatey
choco install opencode

# WinGet
winget install opencode

# Scoop
scoop bucket add extras
scoop install extras/opencode

# Oder über NPM (erfordert Node.js) – Hinweis: Administratorrechte erforderlich
npm install -g opencode-ai
```
