<Note>
このページでは Claude Code がすでにインストールされていることを前提にします。
</Note>

## 1. API キーを取得する

[Harogo コンソール](https://console.harogo.ai/keys)を開き、API キーを作成してコピーします。キーはパスワードと同じように扱い、リポジトリにコミットしたり共有したりしないでください。 支払い方法に応じて、[サブスクリプション用または残高払い用のキー](/ja/pricing#billing-keys)を選んでください。

## 2. Harogo を設定する

Claude Code は Harogo の Anthropic 互換エンドポイントを使用します。設定方法を 1 つ選択してください。

- **環境変数:** Base URL に `https://api.harogo.ai`、Harogo API キーに `ANTHROPIC_AUTH_TOKEN`、対応する Claude モデルに `ANTHROPIC_MODEL` を設定します。例: `claude-sonnet-5-5`。
- **[CC Switch](/ja/troubleshooting#cc-switch):** Claude Code の Provider を追加し、同じ Base URL、API キー、モデルを入力して選択します。

2 つの方法を同時に使用しないでください。CC Switch で管理する場合は、グローバルの `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_MODEL` を解除して、設定が上書きされないようにします。

<CodeGroup>

```shellscript macOS/Linux
export ANTHROPIC_BASE_URL="https://api.harogo.ai"
export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"
export ANTHROPIC_MODEL="claude-sonnet-5-5"
```

```powershell Windows
$env:ANTHROPIC_BASE_URL = "https://api.harogo.ai"
$env:ANTHROPIC_AUTH_TOKEN = "<HAROGO_API_KEY>"
$env:ANTHROPIC_MODEL = "claude-sonnet-5-5"
```

</CodeGroup>

モデル ID を選ぶ前に、[モデルの互換性一覧](/ja#model-compatibility)を確認してください。

## 3. 接続を確認する

プロジェクトディレクトリで、インストール済みのクライアントを起動します。

```shellscript
claude
```

`Reply with exactly: 2` のような簡単なプロンプトを送信します。応答が返り、`/status` に選択した Harogo モデルが表示されることを確認してください。正常な応答だけでは、Harogo が実際に使用されているとは限りません。
