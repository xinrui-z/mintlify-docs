## 補足

- 月次上限はモデルごとに異なります。上限が低いモデルほど共有クォータを速く消費し、上限が高いモデルほどゆっくり消費します。
- 利用上限はモデルごとの別枠ではありません。すべてのモデルが 1 つのクォータを共有しており、各上限はそのモデル単独で使える量を示すだけで、合算はされません。
- 入力範囲が記載されたモデルは段階制の料金です。1 回のリクエストの総入力（入力 + キャッシュ読み取り + キャッシュ書き込み）がしきい値を超えると、そのリクエスト全体が上位の料金で課金されます。
- API の利用額は表の価格で計算します。共有クォータの消費量は、その利用額にモデルごとのクォータ倍率を掛けて算出します。
- アカウント残高で支払う場合は、上表の価格で課金されます。

料金と上限はモデル構成の変化に伴い変更される場合があります。[Harogo コンソール](https://console.harogo.ai/plan) と本ページが最新の情報です。

## 利用状況と上限 {#usage-limits}

Harogoでは、次の利用上限が適用されます。

- 日次上限：\$12 (毎日 **16:00 UTC** にリセット)
- 週次上限：\$30 (サブスクリプションの初回利用から 7 日ごとにリセット)
- 月次上限：\$60 (サブスクリプションの初回利用から 30 日ごとにリセット)

3つの上限はすべて同時に適用されます。 モデルごとに利用上限が異なります。上限が \$60 未満のモデルは共有クォータを速く消費し、\$60 を超えるモデルはゆっくり消費します。各モデルの上限は[料金](#token-prices)をご覧ください。

上限は固定のリクエスト数ではなく米ドル建ての金額で設定されています。実際に得られるリクエスト数は使用するモデルによって変わり、一般に安価なモデルほど多く、高価なモデルほど少なくなります。

現在の利用状況と残クォータは[Harogoコンソール](https://console.harogo.ai/plan)で確認できます。

### サブスクリプション用と残高払い用の API キー {#billing-keys}

[API キーページ](https://console.harogo.ai/keys)で、プランのクォータを使うサブスクリプション用キーと、アカウント残高から支払う残高払い用キーを別々に作成します。利用分は個別に集計されます。サブスクリプションのクォータを使い切っても、残高から自動で引き落とされることはありません。

### リクエスト量の概算

リクエスト数は推定値であり、保証されるものではありません。1 つのコーディングタスクでも、モデルに複数のリクエストが送られる場合があります。

各行は、そのウィンドウのクォータをほぼそのモデルだけで消費した場合を想定しています。複数のモデルを併用すると、同じ共有クォータから一緒に消費されるため、表のリクエスト数を行をまたいで単純に合計することはできません。
