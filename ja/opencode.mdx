インストールの前に、お使いのシステムが次の要件を満たしていることを確認してください。

- **Node.js ≥ 18.0.0**
- お使いのプラットフォーム向けのパッケージマネージャー（任意）：
  - macOS / Linux: `brew`
  - Arch Linux: `paru`
  - Windows: `choco`、`winget`、または`scoop`

## 1. OpenCodeをインストールする

お使いのシステムとツールに合ったインストール方法を選んでください。

### 1. Node.jsでインストールする

```text
# curlスクリプトでクイックインストール
curl -fsSL https://opencode.ai/install | bash

# NPMを使う場合
npm install -g opencode-ai

# Bunを使う場合
bun install -g opencode-ai

# PNPMを使う場合
pnpm install -g opencode-ai

# Yarnを使う場合
yarn global add opencode-ai
```

---

### 2. Homebrewを使う（macOS / Linux）

```text
brew install sst/tap/opencode
```

---

### 3. Paruを使う（Arch Linux）

```text
paru -S opencode-bin
```

---

### 4. Windowsでのインストール

Windowsでは、次のいずれかの方法でOpenCodeをインストールできます。

```text
# Chocolatey
choco install opencode

# WinGet
winget install opencode

# Scoop
scoop bucket add extras
scoop install extras/opencode

# またはNPM経由（Node.jsが必要）— 注意：管理者権限が必要です
npm install -g opencode-ai
```
