# 概要

Harogoはコーディングエージェントのために作られたマルチモデルサブスクリプションサービスです。

割引サブスクリプション価格は初月\$4.90、2か月目以降は\$9.90/月です。現在、割引枠を100枠ご用意しています。残り枠数と確定価格はサブスクリプションページに表示されます。

サブスクリプションに登録すると、1つのHarogoアカウントと1つのAPIキーで複数のコーディングモデルを利用できます。すべてのモデルが同じサブスクリプションのクォータを共有するため、モデルプラットフォームごとに登録、チャージ、管理を行う必要はありません。

# Harogoを選ぶ理由

モデルによって得意なコーディングタスクは異なります。複数のモデルプロバイダーを直接使うと、通常は複数のアカウント、APIキー、残高、レート制限、請求を同時に管理することになります。

Harogoは、コーディングエージェントに適したさまざまなモデルを1つのサービスにまとめています。タスクに応じてモデルを自由に切り替えられ、利用分はすべて1つの共有サブスクリプションクォータから差し引かれます。

現在のモデルは、おおよそ次のグループに分けられます。

- **大規模コードベースと高難度の推論**：Kimi K3.1 Pro、Claude Opus 5.5、GPT-6.1 Sol、GPT-6 Sol、GPT-6 Astra
- **日常のエージェントコーディング、コード生成、デバッグ**：Qwen3.8 Max、GLM-5.3、Claude Sonnet 5.5、Claude Sonnet 5、GPT-6.1 Terra、MiniMax M3、DeepSeek V4 Pro
- **高頻度の呼び出し、素早い応答、コストを重視するタスク**：DeepSeek V4.1 Flash 1017、Claude Haiku 5.5、GPT-6 Luna
- **長時間実行の複数ステップのエージェントワークフロー**：Claude Fable 5.1

これらの分類はモデル選択の参考としてご利用ください。実際の結果はタスク、コンテキスト、ツールの使い方によって異なります。

# 利用開始の手順

1. Harogoにログインし、サブスクリプションに登録します。
2. コンソールでAPIキーを作成してコピーします。
3. Base URLを`https://harogo.ai`に設定します。
4. APIキーを貼り付けます。
5. 利用を開始します。

APIキーは安全に保管してください。公開リポジトリにコミットしたり、他人と共有したりしないでください。

## クライアント別のモデル利用範囲

一部のモデルは特定のクライアントでのみ利用できます。それ以外のモデルに制限はありません。

<Note>
**GPT シリーズ**（GPT-6 Luna、GPT-6 Sol、GPT-6.1 Sol、GPT-6 Astra、GPT-6.1 Terra）は [Codex](/ja/codex) でのみ利用できます。

**Claude シリーズ**（Claude Opus 5.5、Claude Sonnet 5.5、Claude Sonnet 5、Claude Fable 5.1、Claude Haiku 5.5）は [Claude Code](/ja/claude-code) でのみ利用できます。

**その他のモデル**（GLM、Qwen、Kimi、MiniMax、DeepSeek）にクライアント制限はなく、対応するどのクライアントでも利用できます。
</Note>

## 利用状況と上限

Harogoでは、次の利用上限が適用されます。

- 日次上限：\$12
- 週次上限：\$30
- 月次上限：\$60

3つの上限はすべて同時に適用されます。すべてのモデル呼び出しは、共有のサブスクリプションクォータから消費されます。DeepSeek V4 Proのクォータ上限は\$15、その他のモデルのクォータ上限は\$60です。

上限は固定のリクエスト数ではなく米ドル建ての金額で設定されています。実際に得られるリクエスト数は使用するモデルによって変わり、一般に安価なモデルほど多く、高価なモデルほど少なくなります。

現在の利用状況と残クォータは[Harogoコンソール](https://console.harogo.ai/plan)で確認できます。

各行は、そのウィンドウのクォータをほぼそのモデルだけで消費した場合を想定しています。複数のモデルを併用すると、同じ共有クォータから一緒に消費されるため、表のリクエスト数を行をまたいで単純に合計することはできません。

実際のリクエスト量は、コンテキスト長、キャッシュヒット率、推論負荷、出力長などの要因によって変動します。また、コーディングエージェントが1つのタスクを完了するまでには通常複数のモデルリクエストが発生するため、1リクエストは1つのコーディングタスクの完了を意味しません。
