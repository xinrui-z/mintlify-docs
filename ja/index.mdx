# 概要

Harogoはコーディングエージェントのために作られたマルチモデルサブスクリプションサービスです。

割引サブスクリプション価格は初月\$4.90、2か月目以降は\$9.90/月です。現在、割引枠を100枠ご用意しています。残り枠数と確定価格はサブスクリプションページに表示されます。サブスクリプションは毎月自動更新され、Stripe 経由でカードに請求されます。初月価格は Harogo を初めてご契約いただく場合にのみ適用されます。自動更新はコンソールの **プラン** ページからいつでも停止でき、支払い済みの期間が終わるまで引き続きご利用いただけます。

サブスクリプションに登録すると、1つのHarogoアカウントと1つのAPIキーで複数のコーディングモデルを利用できます。すべてのモデルが同じサブスクリプションのクォータを共有するため、モデルプラットフォームごとに登録、チャージ、管理を行う必要はありません。

# Harogoを選ぶ理由

モデルによって得意なコーディングタスクは異なります。複数のモデルプロバイダーを直接使うと、通常は複数のアカウント、APIキー、残高、レート制限、請求を同時に管理することになります。

Harogoは、コーディングエージェントに適したさまざまなモデルを1つのサービスにまとめています。タスクに応じてモデルを自由に切り替えられ、利用分はすべて1つの共有サブスクリプションクォータから差し引かれます。

現在のモデルは、おおよそ次のグループに分けられます。

- **大規模コードベースと高難度の推論**：Kimi K3.1 Pro、Claude Opus 5.5、GPT-6.2 Sol、GPT-6.2 Astra
- **日常のエージェントコーディング、コード生成、デバッグ**：Qwen4 Max、GLM-5.3、Claude Sonnet 5.5、GPT-6.1 Terra、MiniMax M3、DeepSeek V4 Pro
- **高頻度の呼び出し、素早い応答、コストを重視するタスク**：DeepSeek V4.1 Flash 1017、Claude Haiku 5.5、GPT-6 Luna

これらの分類はモデル選択の参考としてご利用ください。実際の結果はタスク、コンテキスト、ツールの使い方によって異なります。

# 利用開始の手順

1. Harogoにログインし、サブスクリプションに登録します。
2. コンソールでAPIキーを作成してコピーします。
3. [Claude Code](/ja/claude-code) では `https://api.harogo.ai`、[Codex](/ja/codex) と [OpenCode](/ja/opencode) では `https://api.harogo.ai/v1` を使用します。各クライアントのガイドに従って設定してください。
4. APIキーを貼り付けます。
5. 利用を開始します。

APIキーは安全に保管してください。公開リポジトリにコミットしたり、他人と共有したりしないでください。

## クライアント別のモデル利用範囲

一部のモデルは特定のクライアントでのみ利用できます。それ以外のモデルに制限はありません。

<Note>
**GPT シリーズ**（GPT-6 Luna、GPT-6.2 Sol、GPT-6.2 Astra、GPT-6.1 Terra）は [Codex](/ja/codex) でのみ利用できます。

**Claude シリーズ**（Claude Opus 5.5、Claude Sonnet 5.5、Claude Haiku 5.5）は [Claude Code](/ja/claude-code) でのみ利用できます。

**その他のモデル**（GLM、Qwen、Kimi、MiniMax、DeepSeek）にクライアント制限はなく、対応するどのクライアントでも利用できます。
</Note>

## 利用状況と上限

Harogoでは、次の利用上限が適用されます。

- 日次上限：\$12
- 週次上限：\$30
- 月次上限：\$60

3つの上限はすべて同時に適用されます。すべてのモデル呼び出しは、共有のサブスクリプションクォータから消費されます。モデルごとに利用上限が異なります。上限が \$60 未満のモデルは共有クォータを速く消費し、\$60 を超えるモデルはゆっくり消費します。各モデルの上限は[料金](/ja/pricing)をご覧ください。

上限は固定のリクエスト数ではなく米ドル建ての金額で設定されています。実際に得られるリクエスト数は使用するモデルによって変わり、一般に安価なモデルほど多く、高価なモデルほど少なくなります。

現在の利用状況と残クォータは[Harogoコンソール](https://console.harogo.ai/plan)で確認できます。

### リクエスト量の概算

以下の表は、Harogo の典型的な利用パターンに基づいてモデルごとのリクエスト数を推定したものです。共有クォータは 1 日 / 1 週間 / 1 か月あたり \$12 / \$30 / \$60 ですが、モデルごとに利用上限が異なり、上限が低いモデルほど共有クォータを速く消費します。表の上限は、そのモデルだけを使った場合に各期間で使える量です。

<Note>
**利用上限はモデルごとの別枠ではありません。** すべてのモデルは、1 日 \$12・1 週間 \$30・1 か月 \$60 の 1 つの共有クォータから消費されます。各モデルの利用上限は、そのモデルだけを使った場合に使える量を示しているだけです。上限は合算されず、同じ期間にすべてのモデルの上限を使い切ることはできません。たとえば Kimi K3.1 Pro の月間上限 \$15 を使い切ると、その月の共有クォータはすべて消費され、他のモデルは使えなくなります。
</Note>

各行は、そのウィンドウのクォータをほぼそのモデルだけで消費した場合を想定しています。複数のモデルを併用すると、同じ共有クォータから一緒に消費されるため、表のリクエスト数を行をまたいで単純に合計することはできません。

実際のリクエスト量は、コンテキスト長、キャッシュヒット率、推論負荷、出力長などの要因によって変動します。また、コーディングエージェントが1つのタスクを完了するまでには通常複数のモデルリクエストが発生するため、1リクエストは1つのコーディングタスクの完了を意味しません。

### 概算の方法

この概算は、次の典型的なリクエストパターンに基づいています。

- **GLM-5.3** — 1リクエストあたり入力トークン約700、キャッシュ読み取りトークン約52,000、出力トークン約150。（GLM-5.2のリクエストパターンを流用しています。）
- **Qwen4 Max** — 1 リクエストあたり約 8,731 入力トークン、31,831 キャッシュ読み取りトークン、2,029 出力トークン。（暫定的な推計値です。）
- **Kimi K3.1 Pro** — 1リクエストあたり入力トークン約1,050、キャッシュ読み取りトークン約76,500、出力トークン約300。（Kimi K3のリクエストパターンを流用しています。）
- **MiniMax M3** — 1リクエストあたり入力トークン約4,381、キャッシュ読み取りトークン約28,768、出力トークン約1,108。
- **DeepSeek V4 Pro** — 1リクエストあたり入力トークン約750、キャッシュ読み取りトークン約82,000、出力トークン約290。
- **DeepSeek V4.1 Flash 1017** — 1リクエストあたり入力トークン約790、キャッシュ読み取りトークン約68,000、出力トークン約280。（DeepSeek V4 Flash 0731のリクエストパターンを流用しています。）
- **Claude Opus 5.5** — 1リクエストあたり入力トークン約580、キャッシュ読み取りトークン約386,230、キャッシュ書き込みトークン約19,476、出力トークン約2,025。（Claude Opus 5のリクエストパターンを流用しています。）
- **Claude Sonnet 5.5** — 1リクエストあたり入力トークン約159、キャッシュ読み取りトークン約129,804、キャッシュ書き込みトークン約6,260、出力トークン約850。 （前バージョンで観測されたリクエストパターンを使用しています。）
- **Claude Haiku 5.5** — 1リクエストあたり入力トークン約700、キャッシュ読み取りトークン約52,000、出力トークン約150。（Claude Haiku 4.5のリクエストパターンを流用しています。）

- **GPT-6.2 Sol** — 1リクエストあたり入力トークン約6,032、キャッシュ読み取りトークン約112,138、出力トークン約678。（GPT-5.6 Solのリクエストパターンを流用しています。）

新しいバージョンのモデルには、当面のあいだ前バージョンで観測されたリクエストパターンを流用しています。リクエスト数 = ウィンドウのクォータ ÷（1リクエストあたりの定価 × 0.1）×（モデルの上限 ÷ \$60）で算出します。

これらの数値は典型的な利用量を見積もるためのものであり、特定のリクエスト数を保証するものではありません。クォータ上限とリクエスト量の概算はサービスの改善に伴い変更される場合があります。最新情報はHarogoコンソールとこのページでご確認ください。
