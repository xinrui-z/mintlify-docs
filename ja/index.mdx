Harogoはコーディングエージェントのために作られたマルチモデルサブスクリプションサービスです。

サブスクリプションに登録すると、1つのHarogoアカウントと1つのAPIキーで複数のコーディングモデルを利用できます。すべてのモデルが同じサブスクリプションのクォータを共有するため、モデルプラットフォームごとに登録、チャージ、管理を行う必要はありません。

## はじめに

1. [Harogo のサブスクリプションページを開く](https://console.harogo.ai/plan)
2. [コンソールで API キーを作成してコピーする](https://console.harogo.ai/keys)
3. お使いのクライアントのガイド（[Claude Code](/ja/claude-code) または [Codex](/ja/codex)）に従って設定します。

APIキーは安全に保管してください。公開リポジトリにコミットしたり、他人と共有したりしないでください。

## 対応モデル {#model-compatibility}

以下の結果は Harogo のベーシックプランに適用されます。[Claude Code](/ja/claude-code) は `POST /v1/messages` を、[Codex](/ja/codex) は `POST /v1/responses` を使用します。

| モデル | モデルID | 得意分野 | Messages | Responses |
| --- | --- | --- | --- | --- |
| GLM-5.4 | `glm-5.4` | 長時間タスク、大規模コードベース、エージェントコーディング | 利用不可 | 対応 |
| Qwen4 Max | `qwen4-max` | 複雑な推論、視覚理解、組み込みツール呼び出し | 利用不可 | 対応 |
| Kimi K3.1 Pro | `kimi-k3.1-pro` | 長時間のコーディング、1Mコンテキスト、フロントエンドと3Dモデリング | 利用不可 | 対応 |
| MiniMax M3 | `minimax-m3` | 高頻度のコーディング、ツール呼び出し、長いコンテキスト | 利用不可 | 対応 |
| DeepSeek V4 Pro | `deepseek-v4-pro` | 推論と複雑なコード生成 | 利用不可 | 対応 |
| DeepSeek V4.1 Flash 1017 | `deepseek-v4.1-flash-1017` | 高速な補完、高頻度の呼び出し、バッチ処理 | 利用不可 | 対応 |
| Claude Opus 5.5 | `claude-opus-5-5` | 複雑なエージェントコーディングと高難度のエンジニアリングタスク | Claude Code からのリクエストのみ許可 | 利用不可 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | 日常的なコーディングと一般的な開発作業 | Claude Code からのリクエストのみ許可 | 利用不可 |
| Claude Haiku 5.5 | `claude-haiku-5-5` | 高速な応答、軽量タスク、バッチ処理 | Claude Code からのリクエストのみ許可 | 利用不可 |
| GPT-6 Luna | `gpt-6-luna` | 高頻度のコーディングと軽量タスク | 利用不可 | 対応 |
| GPT-6.2 Sol | `gpt-6.2-sol` | 高難度のコード生成、レビュー、推論 | 利用不可 | 対応 |
| GPT-6.2 Astra | `gpt-6.2-astra` | 最難関のエンジニアリング課題に挑むフラッグシップ推論 | 利用不可 | 対応 |
| GPT-6.1 Terra | `gpt-6.1-terra` | 日常のエージェントコーディングと一般的なタスク | 利用不可 | 対応 |

上記のモデル名とモデルIDは、Harogoが内部で使用するルーティング用の識別子です。モデルのラインナップ、バージョン、提供状況は変更される場合があります。最新のリストはコンソールでご確認ください。
