Harogo 是面向編程 Agent 的多模型訂閱服務。

訂閱後，你可以通過一個 Harogo 賬戶和 API Key 使用多款編程模型，所有模型共享同一份訂閱配額，無需分別註冊、充值或管理多個模型平台。

## 開始使用

1. [開啟 Harogo 訂閱頁](https://console.harogo.ai/plan)
2. [在控制台建立並複製 API Key](https://console.harogo.ai/keys)
3. 依照客戶端指南完成設定：[Claude Code](/zh/claude-code) 或 [Codex](/zh/codex)。

請妥善保管 API Key，不要將其提交到公開代碼倉庫或分享給他人。

## 支持的模型 {#model-compatibility}

以下結果適用於 Harogo 基礎套餐。[Claude Code](/zh/claude-code) 使用 `POST /v1/messages`，[Codex](/zh/codex) 使用 `POST /v1/responses`。

| 模型 | 模型 ID | 適用場景 | Messages | Responses |
| --- | --- | --- | --- | --- |
| GLM-5.4 | `glm-5.4` | 長時任務、大型代碼庫與 Agent 編程 | 不支援 | 支持 |
| Qwen4 Max | `qwen4-max` | 複雜推理、視覺理解與內建工具調用 | 不支援 | 支持 |
| Kimi K3.1 Pro | `kimi-k3.1-pro` | 長週期編程、1M 長上下文、前端與 3D 建模 | 不支援 | 支持 |
| MiniMax M3 | `minimax-m3` | 高頻編程、工具調用、長上下文 | 不支援 | 支持 |
| DeepSeek V4 Pro | `deepseek-v4-pro` | 推理與複雜代碼生成 | 不支援 | 支持 |
| DeepSeek V4.1 Flash 1017 | `deepseek-v4.1-flash-1017` | 快速補全、高頻調用與批量任務 | 不支援 | 支持 |
| Claude Opus 5.5 | `claude-opus-5-5` | 複雜 Agent 編程與高難度工程任務 | 僅允許 Claude Code 客戶端 | 不支援 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | 日常編程與通用開發任務 | 僅允許 Claude Code 客戶端 | 不支援 |
| Claude Haiku 5.5 | `claude-haiku-5-5` | 快速響應、輕量任務與批處理 | 僅允許 Claude Code 客戶端 | 不支援 |
| GPT-6 Luna | `gpt-6-luna` | 高頻編程與輕量任務 | 不支援 | 支持 |
| GPT-6.2 Sol | `gpt-6.2-sol` | 高難度代碼生成、審查與推理 | 不支援 | 支持 |
| GPT-6.2 Astra | `gpt-6.2-astra` | 旗艦級推理，攻克最高難度的工程問題 | 不支援 | 支持 |
| GPT-6.1 Terra | `gpt-6.1-terra` | 日常 Agent 編程與通用任務 | 不支援 | 支持 |

以上名稱和模型 ID 是 Harogo 使用的路由標識符。模型列表、版本和可用性可能會變化，請以控制檯實際顯示爲準。
