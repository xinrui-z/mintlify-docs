# 簡介

Harogo 是面向編程 Agent 的多模型訂閱服務。

優惠訂閱價格爲首月 \$4.90，之後 \$9.90/月。目前開放 100 個優惠訂閱名額，剩餘名額和實際結算價格以訂閱頁面顯示爲準。

訂閱後，你可以通過一個 Harogo 賬戶和 API Key 使用多款編程模型，所有模型共享同一份訂閱配額，無需分別註冊、充值或管理多個模型平台。

# 爲什麼選擇 Harogo

不同模型擅長不同的編程任務。直接使用多個模型提供商，通常需要同時管理多個賬戶、API Key、餘額、速率限制和賬單。

Harogo 將多款適合編程 Agent 的模型整合到一個服務中。你可以根據任務自由切換模型，並通過同一份訂閱配額統一結算。

目前的模型大致分爲：

- **大型代碼庫與高難度推理**：Kimi K3.1 Pro、Claude Opus 5.5、GPT-6.1 Sol、GPT-6 Sol、GPT-6 Astra
- **日常 Agent 編程、代碼生成與調試**：Qwen4 Max、GLM-5.3、Claude Sonnet 5.5、Claude Sonnet 5、GPT-6.1 Terra、MiniMax M3、DeepSeek V4 Pro
- **高頻調用、快速響應與成本敏感型任務**：DeepSeek V4.1 Flash 1017、Claude Haiku 5.5、GPT-6 Luna
- **長時間運行、步驟較多的 Agent 工作流**：Claude Fable 5.1

這些分類僅供選擇模型時參考，實際效果取決於具體任務、上下文和工具使用方式。

# 開始使用

1. 登錄 Harogo 並完成訂閱。
2. 在控制檯創建並複製 API Key。
3. 將 Base URL 配置爲 `https://harogo.ai`。
4. 粘貼 API Key。
5. 開始使用。

請妥善保管 API Key，不要將其提交到公開代碼倉庫或分享給他人。

## 依客戶端劃分的模型可用範圍

部分模型只能在指定的客戶端使用，其餘模型則不受限制。

<Note>
**GPT 系列模型**（GPT-6 Luna、GPT-6 Sol、GPT-6.1 Sol、GPT-6 Astra、GPT-6.1 Terra）僅能在 [Codex](/zh/codex) 中使用。

**Claude 系列模型**（Claude Opus 5.5、Claude Sonnet 5.5、Claude Sonnet 5、Claude Fable 5.1、Claude Haiku 5.5）僅能在 [Claude Code](/zh/claude-code) 中使用。

**其餘模型**（GLM、Qwen、Kimi、MiniMax、DeepSeek）沒有客戶端限制，可在任何支援的客戶端中使用。
</Note>

## 用量與限制

Harogo 實施以下用量限制：

- 每日限額：\$12
- 每週限額：\$30
- 每月限額：\$60

三項限制同時生效。每一次模型調用都從共享訂閱配額中扣除。每個模型的用量上限均爲 \$60。

限制以美元金額定義，而非固定請求數。你實際能獲得的請求數取決於所使用的模型，通常價格更低的模型能支持更多請求，價格更高的模型則較少。

你可以在 [Harogo 控制檯](https://console.harogo.ai/plan)查看當前用量和剩餘配額。
