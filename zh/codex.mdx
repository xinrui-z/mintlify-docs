<Note>
**本指南僅使用 GPT 系列模型。** Codex 可執行 GPT 系列模型（GPT-6 Luna、GPT-6 Sol、GPT-6.1 Sol、GPT-6 Astra、GPT-6.1 Terra），以及沒有限制的模型（GLM、Qwen、Kimi、MiniMax、DeepSeek）。Claude 系列模型無法在 Codex 中使用，請參考 [Claude Code](/zh/claude-code)。
</Note>

## 安裝

### 官網下載（macOS 版本）

[https://openai.com/zh-Hans-CN/codex/](https://openai.com/zh-Hans-CN/codex/)

### 使用命令行安裝

```bash
npm install -g @openai/codex
```

## 環境變量配置

### 使用配置文件配置

1. 修改 ` ~/.codex/config.toml` 配置文件，增加如下配置：

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. 修改 ` ~/.codex/auth.json` 配置文件，修改如下配置：

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## 使用 Codex

### 在終端中使用

1. 打開終端，定位到你的項目目錄，然後運行 `codex` 命令。

```bash
cd /你的項目路徑
codex
```

2. 根據需求，設置權限。

  alt="Codex 啓動時設置審批權限"
