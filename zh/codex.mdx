<Note>
本頁假設您已安裝 Codex CLI。
</Note>

## 1. 獲取 API Key

開啟 [Harogo 控制台](https://console.harogo.ai/keys)，建立並複製 API Key。請像保護密碼一樣保管它，不要提交到程式碼儲存庫或分享給他人。 請依照計費方式選用[訂閱 Key 或餘額 Key](/zh/pricing#billing-keys)。

## 2. 配置 Harogo

將 Harogo Provider 加入現有的 `~/.codex/config.toml`。保留已有的 Provider 和 Profile，不要替換整個文件。

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

只有在希望 Harogo 成為預設 Profile 時，才設置 `profile = "harogo"`。否則請在啟動 Codex 時選擇該 Profile。

在現有的 `~/.codex/auth.json` 中，只更新 `OPENAI_API_KEY` 的值為 Harogo API Key，保留文件中的其他憑據和內容。

如果使用 [CC Switch](/zh/troubleshooting#cc-switch)，請改為在其中新增相同的 Provider 並啟用。除非清楚哪一項配置優先，否則不要同時使用 CC Switch 和另一份 Provider 配置。

選擇模型 ID 前，請先查看[模型相容性表](/zh#model-compatibility)。

## 3. 確認連接

在專案目錄中啟動已安裝的客戶端：

```shellscript
codex
```

輸入簡單提示，例如 `Reply with exactly: 2`。確認 Codex 返回結果，並確認目前模型是您配置的 Harogo 模型，例如 `gpt-6.2-sol`。僅收到正常回覆，不能證明實際使用的是 Harogo。
