## 說明

- 各模型的每月上限不同。上限較低的模型消耗共享額度較快，上限較高的模型消耗較慢。
- 用量上限不是各模型單獨的額度：所有模型共用一份額度，各上限只表示單獨使用該模型時可用的量，不能相加。
- 標有輸入區間的模型採分段計價：單次請求的總輸入（輸入 + 快取讀取 + 快取寫入）超過門檻後，整次請求按高檔價格計費。
- API 用量按上表價格計算。模型的額度倍率決定這筆用量會消耗多少共享訂閱額度。
- 使用帳戶餘額（而非訂閱額度）呼叫模型時，按上表價格全額扣費。

價格與上限可能隨模型調整而變動。請以 [Harogo 控制台](https://console.harogo.ai/plan) 與本頁面為準。

## 用量與限制 {#usage-limits}

Harogo 實施以下用量限制：

- 每日限額：\$12 (每天 **16:00 UTC** 重置)
- 每週限額：\$30 (從首次使用訂閱起，每 7 天重置)
- 每月限額：\$60 (從首次使用訂閱起，每 30 天重置)

三項限制同時生效。 各模型的用量上限不同：上限低於 \$60 的模型消耗共享額度較快，高於 \$60 的模型消耗較慢。各模型的上限見[價格](#token-prices)。

限制以美元金額定義，而非固定請求數。你實際能獲得的請求數取決於所使用的模型，通常價格更低的模型能支持更多請求，價格更高的模型則較少。

你可以在 [Harogo 控制檯](https://console.harogo.ai/plan)查看當前用量和剩餘配額。

### 訂閱與餘額 API Key {#billing-keys}

在 [API Keys 頁面](https://console.harogo.ai/keys) 分別建立兩種 Key：訂閱 Key 使用方案額度，餘額 Key 從帳戶餘額扣費。兩種用量分開計算，訂閱額度用完後不會自動扣餘額。
