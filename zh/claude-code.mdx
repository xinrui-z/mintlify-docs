### 1. 安裝 Claude Code

#### 本地安裝

<CodeGroup>

```shellscript macOS
curl -fsSL https://claude.ai/install.sh | bash
```

```shellscript Windows
irm https://claude.ai/install.ps1 | iex
```

</CodeGroup>

#### 使用 npm 安裝

需要 [Node.js 18 或更高版本](https://nodejs.org/en/download/)

```shellscript
npm install -g @anthropic-ai/claude-code
```

### 2. 配置 Harogo API

要通過兼容 Anthropic API 的方式來接入 Harogo 的模型服務，需要配置以下環境變量。

1. 將 `ANTHROPIC_BASE_URL` 設置爲 `https://api.harogo.ai/`
2. 將 `ANTHROPIC_AUTH_TOKEN` 設置爲從 [Harogo 平台](https://console.harogo.ai/keys) 獲取的 API Key
3. 將 `ANTHROPIC_MODEL` 設置爲 Harogo 中支持的 Claude 模型，例如 `claude-sonnet-5`。

<Tabs>
  <Tab title="macOS">
    1. 在終端中執行以下命令，查看默認 Shell 類型。

    ```shellscript
    echo $SHELL
    ```

    2. 根據 Shell 類型設置環境變量，命令如下：

    <CodeGroup>

    ```shellscript Zsh
    # 將 <HAROGO_API_KEY> 替換爲你從 Harogo 平台獲取的真實 Key
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.zshrc
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.zshrc
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.zshrc
    ```

    ```shellscript Bash
    # 將 <HAROGO_API_KEY> 替換爲你從 Harogo 平台獲取的真實 Key
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.bash_profile
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.bash_profile
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.bash_profile
    ```

    </CodeGroup>

    3. 在終端中執行下列命令，使環境變量生效。

    <CodeGroup>

    ```shellscript Zsh
    source ~/.zshrc
    ```

    ```shellscript Bash
    source ~/.bash_profile
    ```

    </CodeGroup>

    4. 打開一個新的終端，執行下列命令，查看環境變量是否生效。

    ```shellscript
    echo $ANTHROPIC_BASE_URL
    test -n "$ANTHROPIC_AUTH_TOKEN" && echo "ANTHROPIC_AUTH_TOKEN is set"
    echo $ANTHROPIC_MODEL
    ```
  </Tab>
  <Tab title="Windows">
    在 Windows 中，可以通過 CMD 或 PowerShell 將 Harogo 的 Base URL 和 [API Key](https://console.harogo.ai/keys) 設置爲環境變量。

    <Tabs>
      <Tab title="CMD">
        1. 在 CMD 中運行以下命令，設置環境變量。

        ```shellscript
        REM 將 <HAROGO_API_KEY> 替換爲你從 Harogo 平台獲取的真實 Key
        setx ANTHROPIC_AUTH_TOKEN "<HAROGO_API_KEY>"
        setx ANTHROPIC_BASE_URL "https://api.harogo.ai"
        setx ANTHROPIC_MODEL "claude-sonnet-5"
        ```

        2. 打開一個新的 CMD 窗口，運行以下命令，檢查環境變量是否生效。

        ```shellscript
        if defined ANTHROPIC_AUTH_TOKEN echo ANTHROPIC_AUTH_TOKEN is set
        echo %ANTHROPIC_BASE_URL%
        echo %ANTHROPIC_MODEL%
        ```
      </Tab>
      <Tab title="PowerShell">
        1. 在 PowerShell 中運行以下命令，設置環境變量。

        ```shellscript
        # 將 <HAROGO_API_KEY> 替換爲你從 Harogo 平台獲取的真實 Key
        [Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "<HAROGO_API_KEY>", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.harogo.ai", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-sonnet-5", [EnvironmentVariableTarget]::User)
        ```

        2. 打開一個新的 PowerShell 窗口，運行以下命令，檢查環境變量是否生效。

        ```shellscript
        if ($env:ANTHROPIC_AUTH_TOKEN) { "ANTHROPIC_AUTH_TOKEN is set" }
        echo $env:ANTHROPIC_BASE_URL
        echo $env:ANTHROPIC_MODEL
        ```
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

<Note>
  如果你準備通過 CC Switch 管理 Claude Code，建議不要再額外設置全局 `ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_BASE_URL`、`ANTHROPIC_MODEL`。系統或用戶環境變量可能覆蓋 CC Switch 寫入的 Provider 配置，導致界面裏選擇了正確 Provider，但 Claude Code 實際仍使用舊 Key 或舊模型。
</Note>

### 3. 驗證配置是否生效

完成環境變量或 CC Switch 配置後，建議先用一次最小請求確認 Key、模型和 Anthropic 兼容接口都可用，再啓動長會話。

<CodeGroup>

```bash macOS/Linux
curl https://api.harogo.ai/v1/messages \
  -H "content-type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -H "x-api-key: $ANTHROPIC_AUTH_TOKEN" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 16,
    "messages": [{"role": "user", "content": "1+1, output only the answer"}]
  }'
```

```powershell Windows
curl.exe https://api.harogo.ai/v1/messages `
  -H "content-type: application/json" `
  -H "anthropic-version: 2023-06-01" `
  -H "x-api-key: $env:ANTHROPIC_AUTH_TOKEN" `
  -d "{\"model\":\"claude-sonnet-5\",\"max_tokens\":16,\"messages\":[{\"role\":\"user\",\"content\":\"1+1, output only the answer\"}]}"
```

</CodeGroup>

### 4. 開始使用

完成配置後，進入你的工作目錄，在終端運行 `claude` 命令開始使用 Claude Code。

```bash
$ cd /path/your-project
> claude
```

如果啓動後看到 `Not logged in · Please run /login`，或進入 Anthropic 登錄選項，通常說明 Claude Code 沒有讀取到可用的 Harogo 配置，或首次引導尚未完成。請先確認上一步最小請求可返回 `2`，並檢查 `ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_BASE_URL`、`ANTHROPIC_MODEL` 是否被舊的全局環境變量覆蓋。確認 Key 可用後，如仍進入登錄流程，可按以下步驟跳過首次引導：

1. 定位用戶主目錄下的 `.claude.json` 文件，具體路徑如下：
   - macOS / Linux: `~/.claude.json`
   - Windows: `C:\Users\%USERNAME%\.claude.json`
2. 設置`hasCompletedOnboarding` 字段的值爲 `true`

```json
{
  "hasCompletedOnboarding": true
}
```

3. 保存文件，然後在終端中重新運行 `claude` 。

#### （可選）更多配置模型的方式

Claude Code 支持以下模型配置方式，**按優先級從高到低排列**，優先級高的配置會覆蓋優先級低的配置。

1. **對話期間：** 執行`/model <模型名稱>`命令切換模型。適用於臨時切換模型。

```text
/model claude-sonnet-5
```

2. **啓動 Claude Code 時：** 執行`claude --model <模型名稱>`指定模型。適用於單次會話。

```text
claude --model claude-sonnet-5
```

3. **設置環境變量**：可按任務複雜度配置不同級別的模型，Claude Code 會根據任務類型自動選擇合適的模型。適用於全局生效。

```shellscript
export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5-5"
export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-5-5"
```

其中：

- `ANTHROPIC_DEFAULT_OPUS_MODEL`：用於複雜推理、架構設計等高難度任務。
- `ANTHROPIC_DEFAULT_SONNET_MODEL`：用於代碼編寫、功能實現等日常任務。
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`：用於語法檢查、文件搜索等簡單任務。

4. **在 settings.json 配置文件中永久設置**：在 Claude Code 的用戶配置文件（如 `~/.claude/settings.json`，Windows 爲 `C:\Users\%USERNAME%\.claude\settings.json`）或項目級配置中寫入模型配置信息，可分別進行用戶級或項目級的永久配置。
