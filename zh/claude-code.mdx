<Note>
本頁假設您已安裝 Claude Code。
</Note>

## 1. 獲取 API Key

開啟 [Harogo 控制台](https://console.harogo.ai/keys)，建立並複製 API Key。請像保護密碼一樣保管它，不要提交到程式碼儲存庫或分享給他人。 請依照計費方式選用[訂閱 Key 或餘額 Key](/zh/pricing#billing-keys)。

## 2. 配置 Harogo

Claude Code 使用 Harogo 的 Anthropic 相容端點。請選擇一種配置方式：

- **環境變量：** 將 Base URL 設為 `https://api.harogo.ai`，將 Harogo API Key 設為 `ANTHROPIC_AUTH_TOKEN`，並選擇支援的 Claude 模型，例如 `claude-sonnet-5-5`。
- **[CC Switch](/zh/troubleshooting#cc-switch)：** 新增 Claude Code Provider，填入相同的 Base URL、API Key 和模型，然後選擇該 Provider。

不要同時使用兩種方式。如果由 CC Switch 管理 Provider，請移除或取消設置全局 `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN` 和 `ANTHROPIC_MODEL`，避免覆蓋 CC Switch 的配置。

<CodeGroup>

```shellscript macOS/Linux
export ANTHROPIC_BASE_URL="https://api.harogo.ai"
export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"
export ANTHROPIC_MODEL="claude-sonnet-5-5"
```

```powershell Windows
$env:ANTHROPIC_BASE_URL = "https://api.harogo.ai"
$env:ANTHROPIC_AUTH_TOKEN = "<HAROGO_API_KEY>"
$env:ANTHROPIC_MODEL = "claude-sonnet-5-5"
```

</CodeGroup>

選擇模型 ID 前，請先查看[模型相容性表](/zh#model-compatibility)。

## 3. 確認連接

在專案目錄中啟動已安裝的客戶端：

```shellscript
claude
```

輸入簡單提示，例如 `Reply with exactly: 2`。確認 Claude Code 返回結果，並使用 `/status` 確認顯示的是您選擇的 Harogo 模型。僅收到正常回覆，不能證明實際使用的是 Harogo。
