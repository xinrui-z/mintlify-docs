<Note>
**У цьому посібнику використовуються лише моделі Claude.** Claude Code може запускати моделі Claude (Claude Opus 5.5, Claude Sonnet 5.5, Claude Sonnet 5, Claude Fable 5.1, Claude Haiku 5.5) та моделі без обмежень за клієнтом (GLM, Qwen, Kimi, MiniMax, DeepSeek). Моделі GPT у Claude Code недоступні — див. [Codex](/uk/codex).
</Note>

### 1. Встановлення Claude Code

#### Локальне встановлення

<CodeGroup>

```shellscript macOS
curl -fsSL https://claude.ai/install.sh | bash
```

```shellscript Windows
irm https://claude.ai/install.ps1 | iex
```

</CodeGroup>

#### Встановлення через npm

Потрібен [Node.js 18 або новіший](https://nodejs.org/en/download/)

```shellscript
npm install -g @anthropic-ai/claude-code
```

### 2. Налаштування Harogo API

Щоб підключитися до моделей Harogo через API, сумісний з Anthropic, задайте такі змінні середовища.

1. Задайте для `ANTHROPIC_BASE_URL` значення `https://api.harogo.ai/`
2. Задайте для `ANTHROPIC_AUTH_TOKEN` API-ключ, отриманий на [платформі Harogo](https://console.harogo.ai/keys)
3. Задайте для `ANTHROPIC_MODEL` модель Claude, яку підтримує Harogo, наприклад `claude-sonnet-5`.

<Tabs>
  <Tab title="macOS">
    1. Виконайте в терміналі таку команду, щоб дізнатися, яка оболонка використовується за замовчуванням.

    ```shellscript
    echo $SHELL
    ```

    2. Задайте змінні середовища залежно від типу оболонки:

    <CodeGroup>

    ```shellscript Zsh
    # Замініть <HAROGO_API_KEY> на справжній ключ із платформи Harogo
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.zshrc
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.zshrc
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.zshrc
    ```

    ```shellscript Bash
    # Замініть <HAROGO_API_KEY> на справжній ключ із платформи Harogo
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.bash_profile
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.bash_profile
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.bash_profile
    ```

    </CodeGroup>

    3. Виконайте в терміналі таку команду, щоб застосувати змінні середовища.

    <CodeGroup>

    ```shellscript Zsh
    source ~/.zshrc
    ```

    ```shellscript Bash
    source ~/.bash_profile
    ```

    </CodeGroup>

    4. Відкрийте новий термінал і виконайте такі команди, щоб переконатися, що змінні середовища застосовано.

    ```shellscript
    echo $ANTHROPIC_BASE_URL
    test -n "$ANTHROPIC_AUTH_TOKEN" && echo "ANTHROPIC_AUTH_TOKEN is set"
    echo $ANTHROPIC_MODEL
    ```
  </Tab>
  <Tab title="Windows">
    У Windows базовий URL Harogo та [API-ключ](https://console.harogo.ai/keys) можна задати як змінні середовища через CMD або PowerShell.

    <Tabs>
      <Tab title="CMD">
        1. Виконайте в CMD таку команду, щоб задати змінні середовища.

        ```shellscript
        REM Замініть <HAROGO_API_KEY> на справжній ключ із платформи Harogo
        setx ANTHROPIC_AUTH_TOKEN "<HAROGO_API_KEY>"
        setx ANTHROPIC_BASE_URL "https://api.harogo.ai"
        setx ANTHROPIC_MODEL "claude-sonnet-5"
        ```

        2. Відкрийте нове вікно CMD і виконайте такі команди, щоб переконатися, що змінні середовища застосовано.

        ```shellscript
        if defined ANTHROPIC_AUTH_TOKEN echo ANTHROPIC_AUTH_TOKEN is set
        echo %ANTHROPIC_BASE_URL%
        echo %ANTHROPIC_MODEL%
        ```
      </Tab>
      <Tab title="PowerShell">
        1. Виконайте в PowerShell таку команду, щоб задати змінні середовища.

        ```shellscript
        # Замініть <HAROGO_API_KEY> на справжній ключ із платформи Harogo
        [Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "<HAROGO_API_KEY>", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.harogo.ai", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-sonnet-5", [EnvironmentVariableTarget]::User)
        ```

        2. Відкрийте нове вікно PowerShell і виконайте такі команди, щоб переконатися, що змінні середовища застосовано.

        ```shellscript
        if ($env:ANTHROPIC_AUTH_TOKEN) { "ANTHROPIC_AUTH_TOKEN is set" }
        echo $env:ANTHROPIC_BASE_URL
        echo $env:ANTHROPIC_MODEL
        ```
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

<Note>
  Якщо ви плануєте керувати Claude Code через CC Switch, радимо не задавати додатково глобальні `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` і `ANTHROPIC_MODEL`. Системні або користувацькі змінні середовища можуть перевизначати конфігурацію постачальника, яку записує CC Switch. У результаті в інтерфейсі вибрано правильного постачальника, а Claude Code насправді й далі працює зі старим ключем або старою моделлю.
</Note>

### 3. Перевірка конфігурації

Після налаштування змінних середовища або CC Switch спершу надішліть один мінімальний запит, щоб переконатися, що ключ, модель і Anthropic-сумісний ендпоінт працюють, і лише потім починайте тривалу сесію.

<CodeGroup>

```bash macOS/Linux
curl https://api.harogo.ai/v1/messages \
  -H "content-type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -H "x-api-key: $ANTHROPIC_AUTH_TOKEN" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 16,
    "messages": [{"role": "user", "content": "1+1, output only the answer"}]
  }'
```

```powershell Windows
curl.exe https://api.harogo.ai/v1/messages `
  -H "content-type: application/json" `
  -H "anthropic-version: 2023-06-01" `
  -H "x-api-key: $env:ANTHROPIC_AUTH_TOKEN" `
  -d "{\"model\":\"claude-sonnet-5\",\"max_tokens\":16,\"messages\":[{\"role\":\"user\",\"content\":\"1+1, output only the answer\"}]}"
```

</CodeGroup>

### 4. Початок роботи з Claude Code

Після налаштування перейдіть до робочого каталогу та виконайте в терміналі команду `claude`.

```bash
$ cd /path/your-project
> claude
```

Якщо під час запуску з'являється `Not logged in · Please run /login` або відкривається процес входу в Anthropic, зазвичай це означає, що Claude Code не підхопив робочу конфігурацію Harogo або початкове налаштування ще не пройдено. Спершу переконайтеся, що мінімальний запит із попереднього кроку повертає `2`, і перевірте, чи не перевизначаються `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` або `ANTHROPIC_MODEL` старими глобальними змінними середовища. Якщо ключ точно працює, а вас усе одно перенаправляє на вхід, пропустіть початкове налаштування, виконавши кроки нижче:

#### (Необов'язково) Інші способи налаштування моделі

Claude Code підтримує такі способи налаштування моделі, **перелічені від найвищого пріоритету до найнижчого**: налаштування з вищим пріоритетом перевизначає налаштування з нижчим.

1. **Під час діалогу:** виконайте команду `/model <model-name>`, щоб змінити модель. Підходить для разового перемикання.

```text
/model claude-sonnet-5
```

2. **Під час запуску Claude Code:** виконайте `claude --model <model-name>`, щоб вказати модель. Підходить для однієї сесії.

```text
claude --model claude-sonnet-5
```

3. **Через змінні середовища:** налаштуйте моделі різних рівнів залежно від складності завдання, і Claude Code автоматично вибиратиме відповідну. Діє глобально.

```shellscript
export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5-5"
export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-5-5"
```

Де:

- `ANTHROPIC_DEFAULT_OPUS_MODEL`: для складних міркувань, проєктування архітектури та інших важких завдань.
- `ANTHROPIC_DEFAULT_SONNET_MODEL`: для написання коду, реалізації функцій та інших повсякденних завдань.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`: для перевірки синтаксису, пошуку файлів та інших простих завдань.

4. **Постійно в settings.json:** запишіть конфігурацію моделі в користувацький файл конфігурації Claude Code (наприклад, `~/.claude/settings.json` або `C:\Users\%USERNAME%\.claude\settings.json` у Windows) чи в конфігурацію проєкту, щоб закріпити налаштування на рівні користувача або проєкту.

<Warning>
  Якщо CC Switch показує «Виявлено конфлікт системних змінних середовища» (System environment variable conflict detected), спершу розберіться з `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` і `ANTHROPIC_MODEL`. Ці глобальні змінні перевизначають поточну конфігурацію постачальника, а значення-заглушка на кшталт `ANTHROPIC_AUTH_TOKEN=<HAROGO_API_KEY>` одразу призведе до помилки автентифікації. Переконавшись, що глобальні змінні більше не потрібні, видаліть конфліктні записи в CC Switch або вручну видаліть системні/користувацькі змінні середовища та перезапустіть термінал.
</Warning>
