<Note>
На цій сторінці припускається, що Claude Code уже встановлено.
</Note>

## 1. Отримайте API-ключ

Відкрийте [консоль Harogo](https://console.harogo.ai/keys), створіть API-ключ і скопіюйте його. Зберігайте ключ як пароль. Не додавайте його до репозиторію та не передавайте іншим. Виберіть [ключ підписки або балансу](/uk/pricing#billing-keys) залежно від способу оплати.

## 2. Налаштуйте Harogo

Claude Code використовує сумісний з Anthropic endpoint Harogo. Виберіть один спосіб:

- **Змінні середовища:** встановіть базову URL `https://api.harogo.ai`, використовуйте ключ Harogo як `ANTHROPIC_AUTH_TOKEN` і виберіть підтримувану модель Claude, наприклад `claude-sonnet-5-5`.
- **[CC Switch](/uk/troubleshooting#cc-switch):** додайте провайдера Claude Code з тією самою URL, ключем і моделлю, а потім виберіть його.

Не використовуйте обидва способи одночасно. Якщо провайдером керує CC Switch, видаліть або вимкніть глобальні значення `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` і `ANTHROPIC_MODEL`, щоб вони не перезаписували конфігурацію.

<CodeGroup>

```shellscript macOS/Linux
export ANTHROPIC_BASE_URL="https://api.harogo.ai"
export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"
export ANTHROPIC_MODEL="claude-sonnet-5-5"
```

```powershell Windows
$env:ANTHROPIC_BASE_URL = "https://api.harogo.ai"
$env:ANTHROPIC_AUTH_TOKEN = "<HAROGO_API_KEY>"
$env:ANTHROPIC_MODEL = "claude-sonnet-5-5"
```

</CodeGroup>

Перш ніж вибрати ID моделі, перегляньте [таблицю сумісності моделей](/uk#model-compatibility).

## 3. Перевірте підключення

Запустіть уже встановлений клієнт із каталогу проєкту:

```shellscript
claude
```

Надішліть короткий запит, наприклад `Reply with exactly: 2`. Перевірте відповідь і переконайтеся, що `/status` показує вибрану модель Harogo. Звичайна відповідь сама по собі не підтверджує, що активний Harogo.
