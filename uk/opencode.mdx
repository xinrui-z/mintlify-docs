Перед встановленням переконайтеся, що ваша система відповідає таким вимогам:

- **Node.js ≥ 18.0.0**
- Менеджер пакетів для вашої платформи (необов'язково):
  - macOS / Linux: `brew`
  - Arch Linux: `paru`
  - Windows: `choco`, `winget` або `scoop`

## 1. Встановлення OpenCode

Виберіть спосіб встановлення, який підходить для вашої системи та інструментів.

### 1. Встановлення через Node.js

```text
# Швидке встановлення через скрипт curl
curl -fsSL https://opencode.ai/install | bash

# Через NPM
npm install -g opencode-ai

# Через Bun
bun install -g opencode-ai

# Через PNPM
pnpm install -g opencode-ai

# Через Yarn
yarn global add opencode-ai
```

---

### 2. Через Homebrew (macOS / Linux)

```text
brew install sst/tap/opencode
```

---

### 3. Через Paru (Arch Linux)

```text
paru -S opencode-bin
```

---

### 4. Встановлення у Windows

У Windows OpenCode можна встановити будь-яким із таких способів:

```text
# Chocolatey
choco install opencode

# WinGet
winget install opencode

# Scoop
scoop bucket add extras
scoop install extras/opencode

# Або через NPM (потрібен Node.js); потрібні права адміністратора
npm install -g opencode-ai
```

---
