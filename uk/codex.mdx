**У цьому посібнику використовуються лише моделі GPT.** Codex може запускати моделі GPT (GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra) та моделі без обмежень за клієнтом (GLM, Qwen, Kimi, MiniMax, DeepSeek). Моделі Claude у Codex недоступні — див. [Claude Code](/uk/claude-code).

## Встановлення

### Завантаження з офіційного сайту (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Встановлення через командний рядок

```bash
npm install -g @openai/codex
```

## Налаштування змінних середовища

### Налаштування через файл конфігурації

1. Відкрийте файл `~/.codex/config.toml` і додайте до нього таке:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Відкрийте файл `~/.codex/auth.json` і змініть його так:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Робота з Codex

### У терміналі

1. Відкрийте термінал, перейдіть до каталогу проєкту та виконайте команду `codex`.

```bash
cd /path/to/your/project
codex
```

2. Налаштуйте дозволи за потреби.
