</Note>

## 1. Отримайте API-ключ

Відкрийте [консоль Harogo](https://console.harogo.ai/keys), створіть API-ключ і скопіюйте його. Зберігайте ключ як пароль. Не додавайте його до репозиторію та не передавайте іншим. Виберіть [ключ підписки або балансу](/uk/pricing#billing-keys) залежно від способу оплати.

## 2. Налаштуйте Harogo

Додайте провайдера Harogo до наявного `~/.codex/config.toml`. Збережіть поточні провайдери й профілі; не замінюйте весь файл.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Встановлюйте `profile = "harogo"` лише якщо Harogo має бути профілем за замовчуванням. У наявному `~/.codex/auth.json` оновіть тільки значення `OPENAI_API_KEY`, зберігши інші записи.

Якщо ви використовуєте [CC Switch](/uk/troubleshooting#cc-switch), натомість додайте й увімкніть там того самого провайдера. Не поєднуйте конфігурації, якщо не знаєте, яка має пріоритет.

Перш ніж вибрати ID моделі, перегляньте [таблицю сумісності моделей](/uk#model-compatibility).

## 3. Перевірте підключення

Запустіть уже встановлений клієнт із каталогу проєкту:

```shellscript
codex
```

Надішліть короткий запит, наприклад `Reply with exactly: 2`. Перевірте відповідь і активну модель, наприклад `gpt-6.2-sol`. Звичайна відповідь сама по собі не підтверджує, що активний Harogo.
