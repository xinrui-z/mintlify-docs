<Note>
Trang này giả định Codex CLI đã được cài đặt.
</Note>

## 1. Lấy API key

Mở [console Harogo](https://console.harogo.ai/keys), tạo API key và sao chép. Hãy bảo vệ key như mật khẩu. Không commit key vào repository hoặc chia sẻ key. Chọn [khóa gói đăng ký hoặc khóa số dư](/vi/pricing#billing-keys) theo cách bạn muốn thanh toán.

## 2. Cấu hình Harogo

Thêm provider Harogo vào `~/.codex/config.toml` hiện có. Giữ lại các provider và profile hiện tại; không thay thế toàn bộ file.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Chỉ đặt `profile = "harogo"` nếu muốn Harogo là profile mặc định. Trong `~/.codex/auth.json` hiện có, chỉ cập nhật giá trị `OPENAI_API_KEY` và giữ lại các mục khác.

Nếu dùng [CC Switch](/vi/troubleshooting#cc-switch), hãy thêm và bật provider tương tự ở đó. Không kết hợp các cấu hình nếu bạn chưa biết cấu hình nào được ưu tiên.

Xem [bảng tương thích mô hình](/vi#model-compatibility) trước khi chọn ID mô hình.

## 3. Xác nhận kết nối

Trong thư mục dự án, khởi động client đã cài đặt:

```shellscript
codex
```

Gửi một yêu cầu ngắn như `Reply with exactly: 2`. Kiểm tra phản hồi và model đang hoạt động, chẳng hạn `gpt-6.2-sol`. Chỉ có phản hồi bình thường chưa đủ để xác nhận Harogo đang hoạt động.
