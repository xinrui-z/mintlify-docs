## Cài đặt

### Tải từ trang chính thức (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Cài đặt qua dòng lệnh

```bash
npm install -g @openai/codex
```

## Cấu hình biến môi trường

### Cấu hình qua tệp cấu hình

1. Mở tệp `~/.codex/config.toml` và thêm nội dung sau:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Mở tệp `~/.codex/auth.json` và cập nhật như sau:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Sử dụng Codex

### Trong terminal

1. Mở terminal, chuyển đến thư mục dự án của bạn, rồi chạy lệnh `codex`.

```bash
cd /path/to/your/project
codex
```

2. Thiết lập quyền theo nhu cầu.

<img
  alt="Thiết lập quyền phê duyệt khi khởi động Codex"
  width="1212"
  height="814"
  data-path="public/cn/codex-5.png"

  src="/images/iShot_2026-08-07_17.31.13.png"
/>

3. Nhập một prompt bằng ngôn ngữ tự nhiên — nếu nhận được phản hồi bình thường, nghĩa là bạn đã thiết lập thành công.
