### 1. Zainstaluj Claude Code

#### Instalacja lokalna

<CodeGroup>

```shellscript macOS
curl -fsSL https://claude.ai/install.sh | bash
```

```shellscript Windows
irm https://claude.ai/install.ps1 | iex
```

</CodeGroup>

#### Instalacja przez npm

Wymaga [Node.js w wersji 18 lub nowszej](https://nodejs.org/en/download/)

```shellscript
npm install -g @anthropic-ai/claude-code
```

### 2. Skonfiguruj API Harogo

Aby połączyć się z usługą modeli Harogo przez API zgodne z Anthropic, ustaw następujące zmienne środowiskowe.

1. Ustaw `ANTHROPIC_BASE_URL` na `https://api.harogo.ai/`
2. Ustaw `ANTHROPIC_AUTH_TOKEN` na klucz API uzyskany na [platformie Harogo](https://console.harogo.ai/keys)
3. Ustaw `ANTHROPIC_MODEL` na model Claude obsługiwany przez Harogo, na przykład `claude-sonnet-5`.

<Tabs>
  <Tab title="macOS">
    1. Uruchom w terminalu następujące polecenie, aby sprawdzić domyślną powłokę.

    ```shellscript
    echo $SHELL
    ```

    2. Ustaw zmienne środowiskowe odpowiednio do typu powłoki:

    <CodeGroup>

    ```shellscript Zsh
    # Zastąp <HAROGO_API_KEY> prawdziwym kluczem z platformy Harogo
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.zshrc
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.zshrc
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.zshrc
    ```

    ```shellscript Bash
    # Zastąp <HAROGO_API_KEY> prawdziwym kluczem z platformy Harogo
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.bash_profile
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.bash_profile
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.bash_profile
    ```

    </CodeGroup>

    3. Uruchom w terminalu następujące polecenie, aby zastosować zmienne środowiskowe.

    <CodeGroup>

    ```shellscript Zsh
    source ~/.zshrc
    ```

    ```shellscript Bash
    source ~/.bash_profile
    ```

    </CodeGroup>

    4. Otwórz nowy terminal i uruchom następujące polecenia, aby sprawdzić, czy zmienne środowiskowe zostały zastosowane.

    ```shellscript
    echo $ANTHROPIC_BASE_URL
    test -n "$ANTHROPIC_AUTH_TOKEN" && echo "ANTHROPIC_AUTH_TOKEN is set"
    echo $ANTHROPIC_MODEL
    ```
  </Tab>
  <Tab title="Windows">
    W systemie Windows możesz ustawić Base URL Harogo i [klucz API](https://console.harogo.ai/keys) jako zmienne środowiskowe za pomocą CMD lub PowerShell.

    <Tabs>
      <Tab title="CMD">
        1. Uruchom w CMD następujące polecenie, aby ustawić zmienne środowiskowe.

        ```shellscript
        REM Zastąp <HAROGO_API_KEY> prawdziwym kluczem z platformy Harogo
        setx ANTHROPIC_AUTH_TOKEN "<HAROGO_API_KEY>"
        setx ANTHROPIC_BASE_URL "https://api.harogo.ai"
        setx ANTHROPIC_MODEL "claude-sonnet-5"
        ```

        2. Otwórz nowe okno CMD i uruchom następujące polecenia, aby sprawdzić, czy zmienne środowiskowe zostały zastosowane.

        ```shellscript
        if defined ANTHROPIC_AUTH_TOKEN echo ANTHROPIC_AUTH_TOKEN is set
        echo %ANTHROPIC_BASE_URL%
        echo %ANTHROPIC_MODEL%
        ```
      </Tab>
      <Tab title="PowerShell">
        1. Uruchom w PowerShell następujące polecenie, aby ustawić zmienne środowiskowe.

        ```shellscript
        # Zastąp <HAROGO_API_KEY> prawdziwym kluczem z platformy Harogo
        [Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "<HAROGO_API_KEY>", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.harogo.ai", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-sonnet-5", [EnvironmentVariableTarget]::User)
        ```

        2. Otwórz nowe okno PowerShell i uruchom następujące polecenia, aby sprawdzić, czy zmienne środowiskowe zostały zastosowane.

        ```shellscript
        if ($env:ANTHROPIC_AUTH_TOKEN) { "ANTHROPIC_AUTH_TOKEN is set" }
        echo $env:ANTHROPIC_BASE_URL
        echo $env:ANTHROPIC_MODEL
        ```
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

<Note>
  Jeśli zamierzasz zarządzać Claude Code przez CC Switch, zalecamy, aby nie ustawiać dodatkowo globalnych wartości `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` ani `ANTHROPIC_MODEL`. Zmienne środowiskowe na poziomie systemu lub użytkownika mogą nadpisać konfigurację dostawcy zapisaną przez CC Switch. W efekcie interfejs pokazuje wybranego właściwego dostawcę, a Claude Code w rzeczywistości nadal używa starego klucza lub modelu.
</Note>

### 3. Sprawdź konfigurację

Po skonfigurowaniu zmiennych środowiskowych lub CC Switch, zanim rozpoczniesz dłuższą sesję, wyślij najpierw jedno minimalne zapytanie, aby potwierdzić, że klucz, model i endpoint zgodny z Anthropic działają poprawnie.

<CodeGroup>

```bash macOS/Linux
curl https://api.harogo.ai/v1/messages \
  -H "content-type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -H "x-api-key: $ANTHROPIC_AUTH_TOKEN" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 16,
    "messages": [{"role": "user", "content": "1+1, output only the answer"}]
  }'
```

```powershell Windows
curl.exe https://api.harogo.ai/v1/messages `
  -H "content-type: application/json" `
  -H "anthropic-version: 2023-06-01" `
  -H "x-api-key: $env:ANTHROPIC_AUTH_TOKEN" `
  -d "{\"model\":\"claude-sonnet-5\",\"max_tokens\":16,\"messages\":[{\"role\":\"user\",\"content\":\"1+1, output only the answer\"}]}"
```

</CodeGroup>

### 4. Zacznij korzystać z Claude Code

Po zakończeniu konfiguracji przejdź do katalogu roboczego i uruchom w terminalu polecenie `claude`, aby zacząć.

```bash
$ cd /path/your-project
> claude
```

Jeśli przy uruchomieniu widzisz komunikat `Not logged in · Please run /login` lub trafiasz do procesu logowania Anthropic, zwykle oznacza to, że Claude Code nie wczytał działającej konfiguracji Harogo albo nie ukończono wstępnej konfiguracji przy pierwszym uruchomieniu. Najpierw upewnij się, że minimalne zapytanie z poprzedniego kroku zwraca `2`, i sprawdź, czy `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` lub `ANTHROPIC_MODEL` nie są nadpisywane przez stare globalne zmienne środowiskowe. Jeśli klucz działa, a nadal trafiasz do procesu logowania, możesz pominąć wstępną konfigurację, wykonując poniższe kroki:

1. Znajdź plik `.claude.json` w katalogu domowym:
   - macOS / Linux: `~/.claude.json`
   - Windows: `C:\Users\%USERNAME%\.claude.json`
2. Ustaw pole `hasCompletedOnboarding` na `true`

```json
{
  "hasCompletedOnboarding": true
}
```

3. Zapisz plik, a następnie ponownie uruchom `claude` w terminalu.

#### (Opcjonalnie) Inne sposoby konfiguracji modelu

Claude Code obsługuje następujące sposoby konfiguracji modelu, **uporządkowane od najwyższego do najniższego priorytetu** — ustawienie o wyższym priorytecie nadpisuje ustawienie o niższym priorytecie.

1. **W trakcie rozmowy:** uruchom polecenie `/model <model-name>`, aby przełączyć model. Dobre do jednorazowej zmiany.

```text
/model claude-sonnet-5
```

2. **Przy uruchamianiu Claude Code:** uruchom `claude --model <model-name>`, aby wskazać model. Dobre dla pojedynczej sesji.

```text
claude --model claude-sonnet-5
```

3. **Ustaw zmienne środowiskowe:** skonfiguruj modele różnych poziomów w zależności od złożoności zadań, a Claude Code automatycznie dobierze odpowiedni model do zadania. Działa globalnie.

```shellscript
export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5-5"
export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-5-5"
```

Gdzie:

- `ANTHROPIC_DEFAULT_OPUS_MODEL`: do złożonego rozumowania, projektowania architektury i innych trudnych zadań.
- `ANTHROPIC_DEFAULT_SONNET_MODEL`: do pisania kodu, implementowania funkcji i innych codziennych zadań.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`: do sprawdzania składni, wyszukiwania plików i innych prostych zadań.

4. **Ustaw na stałe w settings.json:** zapisz konfigurację modelu w pliku konfiguracyjnym użytkownika Claude Code (np. `~/.claude/settings.json` lub `C:\Users\%USERNAME%\.claude\settings.json` w systemie Windows) albo w konfiguracji na poziomie projektu, aby ustawić ją na stałe dla użytkownika lub projektu.

<Warning>
  Jeśli CC Switch wyświetla komunikat „Wykryto konflikt systemowych zmiennych środowiskowych” (System environment variable conflict detected), najpierw zajmij się zmiennymi `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` i `ANTHROPIC_MODEL`. Te zmienne globalne nadpisują bieżącą konfigurację dostawcy — wartość zastępcza, taka jak `ANTHROPIC_AUTH_TOKEN=<HAROGO_API_KEY>`, od razu spowoduje błąd uwierzytelniania. Gdy masz pewność, że zmienne globalne nie są już potrzebne, usuń konfliktujące wpisy w CC Switch albo ręcznie usuń zmienne środowiskowe systemu lub użytkownika i uruchom ponownie terminal.
</Warning>
