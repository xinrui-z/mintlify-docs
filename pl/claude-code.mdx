## 1. Pobierz klucz API

Otwórz [konsolę Harogo](https://console.harogo.ai/keys), utwórz klucz API i skopiuj go. Traktuj go jak hasło. Nie umieszczaj go w repozytorium ani nie udostępniaj. Wybierz [klucz subskrypcji lub klucz salda](/pl/pricing#billing-keys) zależnie od wybranego sposobu rozliczania.

## 2. Skonfiguruj Harogo

Claude Code używa zgodnego z Anthropic endpointu Harogo. Wybierz jedną metodę:

- **Zmienne środowiskowe:** ustaw URL bazowy na `https://api.harogo.ai`, użyj klucza Harogo jako `ANTHROPIC_AUTH_TOKEN` i wybierz obsługiwany model Claude, na przykład `claude-sonnet-5-5`.
- **[CC Switch](/pl/troubleshooting#cc-switch):** dodaj dostawcę Claude Code z tym samym URL-em, kluczem i modelem, a następnie go wybierz.

Nie używaj obu metod jednocześnie. Jeśli dostawcą zarządza CC Switch, usuń lub wyłącz globalne wartości `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` i `ANTHROPIC_MODEL`, aby nie nadpisywały konfiguracji.

<CodeGroup>

```shellscript macOS/Linux
export ANTHROPIC_BASE_URL="https://api.harogo.ai"
export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"
export ANTHROPIC_MODEL="claude-sonnet-5-5"
```

```powershell Windows
$env:ANTHROPIC_BASE_URL = "https://api.harogo.ai"
$env:ANTHROPIC_AUTH_TOKEN = "<HAROGO_API_KEY>"
$env:ANTHROPIC_MODEL = "claude-sonnet-5-5"
```

</CodeGroup>

Przed wyborem identyfikatora modelu sprawdź [tabelę zgodności modeli](/pl#model-compatibility).

## 3. Sprawdź połączenie

Uruchom zainstalowanego klienta w katalogu projektu:

```shellscript
claude
```

Wyślij krótkie polecenie, na przykład `Reply with exactly: 2`. Sprawdź odpowiedź i upewnij się, że `/status` pokazuje wybrany model Harogo. Sama poprawna odpowiedź nie potwierdza jeszcze aktywnego Harogo.
