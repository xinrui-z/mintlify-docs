---
title: "Troubleshooting"
---

## Invalid API key

Check that the key is active on the [API Keys page](https://console.harogo.ai/keys) and that your client uses that key.

## Model not found or denied

Check the exact model ID and the endpoint in the [model compatibility table](/#model-compatibility).

## Still using the old provider

Check the active provider, base URL, and model in your client. If you use CC Switch, check that Harogo is selected and no separate settings override it.

## Quota reached

Check which usage limit you reached in the [Harogo console](https://console.harogo.ai/plan).

To continue using Harogo before the limit resets, manually switch to a balance key. See [quota reset times](/pricing#usage-limits).

## CC Switch {#cc-switch}

[CC Switch releases](https://github.com/farion1231/cc-switch/releases) is the download page. CC Switch is optional: use it to switch providers instead of editing your client configuration by hand.
