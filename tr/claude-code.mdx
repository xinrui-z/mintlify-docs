<Note>
Bu sayfa Claude Code'un zaten yüklü olduğunu varsayar.
</Note>

## 1. API anahtarı alın

[Harogo konsolunu](https://console.harogo.ai/keys) açın, bir API anahtarı oluşturun ve kopyalayın. Anahtarı parola gibi koruyun. Bir depoya göndermeyin veya paylaşmayın. Ödeme tercihinize göre bir [abonelik veya bakiye anahtarı](/tr/pricing#billing-keys) seçin.

## 2. Harogo'yu yapılandırın

Claude Code, Harogo'nun Anthropic uyumlu uç noktasını kullanır. Bir yöntem seçin:

- **Ortam değişkenleri:** temel URL olarak `https://api.harogo.ai`, Harogo anahtarınız için `ANTHROPIC_AUTH_TOKEN` ve `claude-sonnet-5-5` gibi desteklenen bir Claude modeli kullanın.
- **[CC Switch](/tr/troubleshooting#cc-switch):** aynı temel URL, anahtar ve model ile bir Claude Code sağlayıcısı ekleyin ve seçin.

İki yöntemi aynı anda kullanmayın. Sağlayıcıyı CC Switch yönetiyorsa genel `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` ve `ANTHROPIC_MODEL` değerlerini kaldırın veya devre dışı bırakın.

<CodeGroup>

```shellscript macOS/Linux
export ANTHROPIC_BASE_URL="https://api.harogo.ai"
export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"
export ANTHROPIC_MODEL="claude-sonnet-5-5"
```

```powershell Windows
$env:ANTHROPIC_BASE_URL = "https://api.harogo.ai"
$env:ANTHROPIC_AUTH_TOKEN = "<HAROGO_API_KEY>"
$env:ANTHROPIC_MODEL = "claude-sonnet-5-5"
```

</CodeGroup>

Model kimliği seçmeden önce [model uyumluluk tablosuna](/tr#model-compatibility) bakın.

## 3. Bağlantıyı doğrulayın

Proje dizininizde yüklü istemciyi başlatın:

```shellscript
claude
```

`Reply with exactly: 2` gibi kısa bir istek gönderin. Yanıtı ve `/status` komutunun seçtiğiniz Harogo modelini gösterdiğini kontrol edin. Normal bir yanıt tek başına Harogo'nun etkin olduğunu kanıtlamaz.
