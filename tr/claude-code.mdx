<Note>
**Bu kılavuz yalnızca Claude modellerini kullanır.** Claude Code, Claude modellerini (Claude Opus 5.5, Claude Sonnet 5.5, Claude Sonnet 5, Claude Fable 5.1, Claude Haiku 5.5) ve istemci kısıtlaması olmayan modelleri (GLM, Qwen, Kimi, MiniMax, DeepSeek) çalıştırabilir. GPT modelleri Claude Code'da kullanılamaz — bkz. [Codex](/tr/codex).
</Note>

### 1. Claude Code'u Kurun

#### Yerel Kurulum

<CodeGroup>

```shellscript macOS
curl -fsSL https://claude.ai/install.sh | bash
```

```shellscript Windows
irm https://claude.ai/install.ps1 | iex
```

</CodeGroup>

#### npm ile Kurulum

[Node.js 18 veya üzeri](https://nodejs.org/en/download/) gerektirir

```shellscript
npm install -g @anthropic-ai/claude-code
```

### 2. Harogo API'sini Yapılandırın

Harogo'nun model hizmetine Anthropic uyumlu API üzerinden bağlanmak için aşağıdaki ortam değişkenlerini ayarlayın.

1. `ANTHROPIC_BASE_URL` değerini `https://api.harogo.ai/` olarak ayarlayın
2. `ANTHROPIC_AUTH_TOKEN` değerini [Harogo platformundan](https://console.harogo.ai/keys) aldığınız API anahtarı olarak ayarlayın
3. `ANTHROPIC_MODEL` değerini Harogo'nun desteklediği bir Claude modeli olarak ayarlayın, örneğin `claude-sonnet-5`.

<Tabs>
  <Tab title="macOS">
    1. Varsayılan kabuğunuzu kontrol etmek için terminalde aşağıdaki komutu çalıştırın.

    ```shellscript
    echo $SHELL
    ```

    2. Ortam değişkenlerini kabuk türünüze göre ayarlayın:

    <CodeGroup>

    ```shellscript Zsh
    # <HAROGO_API_KEY> değerini Harogo platformundan aldığınız gerçek anahtarla değiştirin
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.zshrc
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.zshrc
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.zshrc
    ```

    ```shellscript Bash
    # <HAROGO_API_KEY> değerini Harogo platformundan aldığınız gerçek anahtarla değiştirin
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.bash_profile
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.bash_profile
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.bash_profile
    ```

    </CodeGroup>

    3. Ortam değişkenlerini uygulamak için terminalde aşağıdaki komutu çalıştırın.

    <CodeGroup>

    ```shellscript Zsh
    source ~/.zshrc
    ```

    ```shellscript Bash
    source ~/.bash_profile
    ```

    </CodeGroup>

    4. Yeni bir terminal açın ve ortam değişkenlerinin etkin olduğunu doğrulamak için aşağıdaki komutları çalıştırın.

    ```shellscript
    echo $ANTHROPIC_BASE_URL
    test -n "$ANTHROPIC_AUTH_TOKEN" && echo "ANTHROPIC_AUTH_TOKEN is set"
    echo $ANTHROPIC_MODEL
    ```
  </Tab>
  <Tab title="Windows">
    Windows'ta Harogo'nun Taban URL'sini ve [API anahtarını](https://console.harogo.ai/keys) CMD veya PowerShell kullanarak ortam değişkeni olarak ayarlayabilirsiniz.

    <Tabs>
      <Tab title="CMD">
        1. Ortam değişkenlerini ayarlamak için CMD'de aşağıdaki komutu çalıştırın.

        ```shellscript
        REM <HAROGO_API_KEY> değerini Harogo platformundan aldığınız gerçek anahtarla değiştirin
        setx ANTHROPIC_AUTH_TOKEN "<HAROGO_API_KEY>"
        setx ANTHROPIC_BASE_URL "https://api.harogo.ai"
        setx ANTHROPIC_MODEL "claude-sonnet-5"
        ```

        2. Yeni bir CMD penceresi açın ve ortam değişkenlerinin etkin olduğunu doğrulamak için aşağıdaki komutları çalıştırın.

        ```shellscript
        if defined ANTHROPIC_AUTH_TOKEN echo ANTHROPIC_AUTH_TOKEN is set
        echo %ANTHROPIC_BASE_URL%
        echo %ANTHROPIC_MODEL%
        ```
      </Tab>
      <Tab title="PowerShell">
        1. Ortam değişkenlerini ayarlamak için PowerShell'de aşağıdaki komutu çalıştırın.

        ```shellscript
        # <HAROGO_API_KEY> değerini Harogo platformundan aldığınız gerçek anahtarla değiştirin
        [Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "<HAROGO_API_KEY>", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.harogo.ai", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-sonnet-5", [EnvironmentVariableTarget]::User)
        ```

        2. Yeni bir PowerShell penceresi açın ve ortam değişkenlerinin etkin olduğunu doğrulamak için aşağıdaki komutları çalıştırın.

        ```shellscript
        if ($env:ANTHROPIC_AUTH_TOKEN) { "ANTHROPIC_AUTH_TOKEN is set" }
        echo $env:ANTHROPIC_BASE_URL
        echo $env:ANTHROPIC_MODEL
        ```
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

<Note>
  Claude Code'u CC Switch üzerinden yönetecekseniz, ayrıca genel `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` veya `ANTHROPIC_MODEL` değerleri ayarlamamanızı öneririz. Sistem veya kullanıcı düzeyindeki ortam değişkenleri, CC Switch'in yazdığı sağlayıcı yapılandırmasını geçersiz kılabilir. Bu durumda arayüzde doğru sağlayıcı seçili görünse de Claude Code aslında hâlâ eski bir anahtar veya modelle çalışır.
</Note>

### 3. Yapılandırmayı Doğrulayın

Ortam değişkenlerini veya CC Switch'i ayarladıktan sonra, uzun bir oturuma başlamadan önce anahtarın, modelin ve Anthropic uyumlu uç noktanın çalıştığını doğrulamak için önce tek bir minimal istek gönderin.

<CodeGroup>

```bash macOS/Linux
curl https://api.harogo.ai/v1/messages \
  -H "content-type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -H "x-api-key: $ANTHROPIC_AUTH_TOKEN" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 16,
    "messages": [{"role": "user", "content": "1+1, output only the answer"}]
  }'
```

```powershell Windows
curl.exe https://api.harogo.ai/v1/messages `
  -H "content-type: application/json" `
  -H "anthropic-version: 2023-06-01" `
  -H "x-api-key: $env:ANTHROPIC_AUTH_TOKEN" `
  -d "{\"model\":\"claude-sonnet-5\",\"max_tokens\":16,\"messages\":[{\"role\":\"user\",\"content\":\"1+1, output only the answer\"}]}"
```

</CodeGroup>

### 4. Claude Code'u Kullanmaya Başlayın

Yapılandırma tamamlandıktan sonra çalışma dizininize gidin ve başlamak için terminalde `claude` komutunu çalıştırın.

```bash
$ cd /path/your-project
> claude
```

Başlangıçta `Not logged in · Please run /login` mesajını görüyorsanız veya Anthropic giriş akışına yönlendiriliyorsanız, bu genellikle Claude Code'un çalışan bir Harogo yapılandırmasını algılamadığı ya da ilk kullanım kurulumunun tamamlanmadığı anlamına gelir. Önce bir önceki adımdaki minimal isteğin `2` döndürdüğünü doğrulayın ve `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` veya `ANTHROPIC_MODEL` değerlerinin eski genel ortam değişkenleri tarafından geçersiz kılınıp kılınmadığını kontrol edin. Anahtarın çalıştığından emin olduktan sonra hâlâ giriş akışına yönlendiriliyorsanız, aşağıdaki adımlarla ilk kullanım kurulumunu atlayabilirsiniz:

1. Ana dizininizdeki `.claude.json` dosyasını bulun:
   - macOS / Linux: `~/.claude.json`
   - Windows: `C:\Users\%USERNAME%\.claude.json`
2. `hasCompletedOnboarding` alanını `true` olarak ayarlayın

```json
{
  "hasCompletedOnboarding": true
}
```

3. Dosyayı kaydedin, ardından terminalde `claude` komutunu yeniden çalıştırın.

#### (İsteğe Bağlı) Modeli Yapılandırmanın Diğer Yolları

Claude Code, modeli yapılandırmak için aşağıdaki yolları destekler; bunlar **en yüksek öncelikten en düşüğe doğru sıralanmıştır** — yüksek öncelikli bir ayar, düşük öncelikli olanı geçersiz kılar.

1. **Sohbet sırasında:** modeli değiştirmek için `/model <model-name>` komutunu çalıştırın. Tek seferlik geçişler için uygundur.

```text
/model claude-sonnet-5
```

2. **Claude Code'u başlatırken:** bir model belirtmek için `claude --model <model-name>` komutunu çalıştırın. Tek bir oturum için uygundur.

```text
claude --model claude-sonnet-5
```

3. **Ortam değişkenlerini ayarlayın:** görev karmaşıklığına göre farklı seviyelerde modeller yapılandırın; Claude Code göreve uygun modeli otomatik olarak seçer. Genel olarak uygulanır.

```shellscript
export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5-5"
export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-5-5"
```

Burada:

- `ANTHROPIC_DEFAULT_OPUS_MODEL`: karmaşık muhakeme, mimari tasarım ve diğer yüksek zorluktaki görevler için.
- `ANTHROPIC_DEFAULT_SONNET_MODEL`: kod yazma, özellik geliştirme ve diğer günlük görevler için.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`: sözdizimi kontrolü, dosya arama ve diğer basit görevler için.

4. **settings.json içinde kalıcı olarak ayarlayın:** model yapılandırmasını Claude Code'un kullanıcı yapılandırma dosyasına (ör. `~/.claude/settings.json` veya Windows'ta `C:\Users\%USERNAME%\.claude\settings.json`) ya da proje düzeyindeki bir yapılandırmaya yazarak kalıcı bir kullanıcı veya proje düzeyi ayar oluşturun.

<Warning>
  CC Switch "Sistem ortam değişkeni çakışması algılandı" (System environment variable conflict detected) uyarısı gösterirse, önce `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` ve `ANTHROPIC_MODEL` değişkenleriyle ilgilenin. Genel değişkenlere artık ihtiyacınız olmadığından emin olduğunuzda, çakışan girdileri CC Switch'te kaldırın veya sistem/kullanıcı ortam değişkenlerini elle silip terminalinizi yeniden başlatın.
</Warning>
