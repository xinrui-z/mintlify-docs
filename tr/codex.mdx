<Note>
**Bu kılavuz yalnızca GPT modellerini kullanır.** Codex, GPT modellerini (GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra) ve istemci kısıtlaması olmayan modelleri (GLM, Qwen, Kimi, MiniMax, DeepSeek) çalıştırabilir. Claude modelleri Codex'te kullanılamaz — bkz. [Claude Code](/tr/claude-code).
</Note>

## Kurulum

### Resmi siteden indirin (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Komut satırından kurun

```bash
npm install -g @openai/codex
```

## Ortam Değişkeni Yapılandırması

### Yapılandırma dosyasıyla yapılandırın

1. `~/.codex/config.toml` dosyanızı düzenleyin ve aşağıdakileri ekleyin:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. `~/.codex/auth.json` dosyanızı düzenleyin ve aşağıdaki gibi güncelleyin:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Codex'i Kullanma

### Terminalde

1. Bir terminal açın, proje dizininize gidin ve ardından `codex` komutunu çalıştırın.

```bash
cd /path/to/your/project
codex
```

2. İzinleri ihtiyacınıza göre ayarlayın.

<img
  alt="Codex başlatılırken onay izinlerinin ayarlanması"

3. Doğal dilde bir istem yazın — normal bir yanıt alırsanız kurulum başarıyla tamamlanmıştır.
