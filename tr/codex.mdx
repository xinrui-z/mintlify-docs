</Note>

## 1. API anahtarı alın

[Harogo konsolunu](https://console.harogo.ai/keys) açın, bir API anahtarı oluşturun ve kopyalayın. Anahtarı parola gibi koruyun. Bir depoya göndermeyin veya paylaşmayın. Ödeme tercihinize göre bir [abonelik veya bakiye anahtarı](/tr/pricing#billing-keys) seçin.

## 2. Harogo'yu yapılandırın

Harogo sağlayıcısını mevcut `~/.codex/config.toml` dosyanıza ekleyin. Mevcut sağlayıcıları ve profilleri koruyun; dosyanın tamamını değiştirmeyin.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Harogo'nun varsayılan profil olmasını istiyorsanız `profile = "harogo"` ayarlayın. Mevcut `~/.codex/auth.json` içinde yalnızca `OPENAI_API_KEY` değerini güncelleyin ve diğer girdileri koruyun.

[CC Switch](/tr/troubleshooting#cc-switch) kullanıyorsanız aynı sağlayıcıyı oraya ekleyip etkinleştirin. Önceliği bilmiyorsanız yapılandırmaları birleştirmeyin.

Model kimliği seçmeden önce [model uyumluluk tablosuna](/tr#model-compatibility) bakın.

## 3. Bağlantıyı doğrulayın

Proje dizininizde yüklü istemciyi başlatın:

```shellscript
codex
```

`Reply with exactly: 2` gibi kısa bir istek gönderin. Yanıtı ve etkin modelin yapılandırdığınız Harogo modeli (ör. `gpt-6.2-sol`) olduğunu kontrol edin. Normal bir yanıt tek başına Harogo'nun etkin olduğunu kanıtlamaz.
