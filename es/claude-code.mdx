<Note>
Esta página supone que Claude Code ya está instalado.
</Note>

## 1. Obtén una clave de API

Abre la [consola de Harogo](https://console.harogo.ai/keys), crea una clave de API y cópiala. Trátala como una contraseña. No la subas a un repositorio ni la compartas. Elige una [clave de suscripción o de saldo](/es/pricing#billing-keys) según cómo quieras pagar.

## 2. Configura Harogo

Claude Code usa el endpoint compatible con Anthropic de Harogo. Elige un método:

- **Variables de entorno:** usa `https://api.harogo.ai` como URL base, tu clave de Harogo como `ANTHROPIC_AUTH_TOKEN` y un modelo Claude compatible, por ejemplo `claude-sonnet-5-5`.
- **[CC Switch](/es/troubleshooting#cc-switch):** añade un proveedor de Claude Code con la misma URL base, clave y modelo, y selecciónalo.

No uses ambos métodos a la vez. Si CC Switch administra el proveedor, elimina o desactiva los valores globales `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` y `ANTHROPIC_MODEL` para que no sobrescriban la configuración.

<CodeGroup>

```shellscript macOS/Linux
export ANTHROPIC_BASE_URL="https://api.harogo.ai"
export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"
export ANTHROPIC_MODEL="claude-sonnet-5-5"
```

```powershell Windows
$env:ANTHROPIC_BASE_URL = "https://api.harogo.ai"
$env:ANTHROPIC_AUTH_TOKEN = "<HAROGO_API_KEY>"
$env:ANTHROPIC_MODEL = "claude-sonnet-5-5"
```

</CodeGroup>

Consulta la [tabla de compatibilidad de modelos](/es#model-compatibility) antes de elegir un ID de modelo.

## 3. Confirma la conexión

Inicia el cliente ya instalado desde el directorio de tu proyecto:

```shellscript
claude
```

Envía una solicitud mínima como `Reply with exactly: 2`. Comprueba la respuesta y que `/status` muestre el modelo de Harogo elegido. Una respuesta normal por sí sola no confirma que Harogo esté activo.
