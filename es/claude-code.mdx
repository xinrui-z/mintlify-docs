### 1. Instalar Claude Code

#### Instalación local

<CodeGroup>

```shellscript macOS
curl -fsSL https://claude.ai/install.sh | bash
```

```shellscript Windows
irm https://claude.ai/install.ps1 | iex
```

</CodeGroup>

#### Instalar con npm

Requiere [Node.js 18 o posterior](https://nodejs.org/en/download/)

```shellscript
npm install -g @anthropic-ai/claude-code
```

### 2. Configurar la API de Harogo

Para conectarte al servicio de modelos de Harogo a través de la API compatible con Anthropic, configura las siguientes variables de entorno.

1. Configura `ANTHROPIC_BASE_URL` como `https://api.harogo.ai/`
2. Configura `ANTHROPIC_AUTH_TOKEN` con la clave de API que obtuviste en la [plataforma de Harogo](https://console.harogo.ai/keys)
3. Configura `ANTHROPIC_MODEL` con un modelo Claude compatible con Harogo, por ejemplo `claude-sonnet-5`.

<Tabs>
  <Tab title="macOS">
    1. Ejecuta el siguiente comando en tu terminal para ver cuál es tu shell predeterminada.

    ```shellscript
    echo $SHELL
    ```

    2. Configura las variables de entorno según tu tipo de shell:

    <CodeGroup>

    ```shellscript Zsh
    # Sustituye <HAROGO_API_KEY> por la clave real de tu plataforma de Harogo
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.zshrc
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.zshrc
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.zshrc
    ```

    ```shellscript Bash
    # Sustituye <HAROGO_API_KEY> por la clave real de tu plataforma de Harogo
    echo 'export ANTHROPIC_BASE_URL="https://api.harogo.ai"' >> ~/.bash_profile
    echo 'export ANTHROPIC_AUTH_TOKEN="<HAROGO_API_KEY>"' >> ~/.bash_profile
    echo 'export ANTHROPIC_MODEL="claude-sonnet-5"' >> ~/.bash_profile
    ```

    </CodeGroup>

    3. Ejecuta el siguiente comando en tu terminal para aplicar las variables de entorno.

    <CodeGroup>

    ```shellscript Zsh
    source ~/.zshrc
    ```

    ```shellscript Bash
    source ~/.bash_profile
    ```

    </CodeGroup>

    4. Abre una terminal nueva y ejecuta los siguientes comandos para confirmar que las variables de entorno se aplicaron.

    ```shellscript
    echo $ANTHROPIC_BASE_URL
    test -n "$ANTHROPIC_AUTH_TOKEN" && echo "ANTHROPIC_AUTH_TOKEN is set"
    echo $ANTHROPIC_MODEL
    ```
  </Tab>
  <Tab title="Windows">
    En Windows, puedes configurar la URL base y la [clave de API](https://console.harogo.ai/keys) de Harogo como variables de entorno con CMD o con PowerShell.

    <Tabs>
      <Tab title="CMD">
        1. Ejecuta el siguiente comando en CMD para configurar las variables de entorno.

        ```shellscript
        REM Sustituye <HAROGO_API_KEY> por la clave real de tu plataforma de Harogo
        setx ANTHROPIC_AUTH_TOKEN "<HAROGO_API_KEY>"
        setx ANTHROPIC_BASE_URL "https://api.harogo.ai"
        setx ANTHROPIC_MODEL "claude-sonnet-5"
        ```

        2. Abre una ventana nueva de CMD y ejecuta los siguientes comandos para confirmar que las variables de entorno se aplicaron.

        ```shellscript
        if defined ANTHROPIC_AUTH_TOKEN echo ANTHROPIC_AUTH_TOKEN is set
        echo %ANTHROPIC_BASE_URL%
        echo %ANTHROPIC_MODEL%
        ```
      </Tab>
      <Tab title="PowerShell">
        1. Ejecuta el siguiente comando en PowerShell para configurar las variables de entorno.

        ```shellscript
        # Sustituye <HAROGO_API_KEY> por la clave real de tu plataforma de Harogo
        [Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "<HAROGO_API_KEY>", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.harogo.ai", [EnvironmentVariableTarget]::User)
        [Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-sonnet-5", [EnvironmentVariableTarget]::User)
        ```

        2. Abre una ventana nueva de PowerShell y ejecuta los siguientes comandos para confirmar que las variables de entorno se aplicaron.

        ```shellscript
        if ($env:ANTHROPIC_AUTH_TOKEN) { "ANTHROPIC_AUTH_TOKEN is set" }
        echo $env:ANTHROPIC_BASE_URL
        echo $env:ANTHROPIC_MODEL
        ```
      </Tab>
    </Tabs>
  </Tab>
</Tabs>

<Note>
  Si vas a gestionar Claude Code con CC Switch, te recomendamos no configurar también valores globales de `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` o `ANTHROPIC_MODEL`. Las variables de entorno a nivel de sistema o de usuario pueden sobrescribir la configuración del proveedor que escribe CC Switch, de modo que la interfaz muestra seleccionado el proveedor correcto mientras Claude Code sigue usando en realidad una clave o un modelo antiguos.
</Note>

### 3. Verificar la configuración

Después de configurar las variables de entorno o CC Switch, envía primero una solicitud mínima para confirmar que la clave, el modelo y el endpoint compatible con Anthropic funcionan, antes de empezar una sesión más larga.

<CodeGroup>

```bash macOS/Linux
curl https://api.harogo.ai/v1/messages \
  -H "content-type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -H "x-api-key: $ANTHROPIC_AUTH_TOKEN" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 16,
    "messages": [{"role": "user", "content": "1+1, output only the answer"}]
  }'
```

```powershell Windows
curl.exe https://api.harogo.ai/v1/messages `
  -H "content-type: application/json" `
  -H "anthropic-version: 2023-06-01" `
  -H "x-api-key: $env:ANTHROPIC_AUTH_TOKEN" `
  -d "{\"model\":\"claude-sonnet-5\",\"max_tokens\":16,\"messages\":[{\"role\":\"user\",\"content\":\"1+1, output only the answer\"}]}"
```

</CodeGroup>

### 4. Empezar a usar Claude Code

Una vez configurado, ve a tu directorio de trabajo y ejecuta el comando `claude` en tu terminal para empezar.

```bash
$ cd /path/your-project
> claude
```

Si al iniciar ves `Not logged in · Please run /login`, o se abre el flujo de inicio de sesión de Anthropic, normalmente significa que Claude Code no detectó una configuración de Harogo válida o que no se completó la configuración inicial. Primero confirma que la solicitud mínima del paso anterior devuelve `2` y comprueba si `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` o `ANTHROPIC_MODEL` están siendo sobrescritas por variables de entorno globales antiguas. Si ya confirmaste que la clave funciona y aun así se abre el flujo de inicio de sesión, puedes omitir la configuración inicial con estos pasos:

   - macOS / Linux: `~/.claude.json`

#### (Opcional) Otras formas de configurar el modelo

Claude Code permite configurar el modelo de las siguientes formas, **ordenadas de mayor a menor prioridad**: una configuración de mayor prioridad sobrescribe a una de menor prioridad.

1. **Durante una conversación:** ejecuta el comando `/model <model-name>` para cambiar de modelo. Útil para un cambio puntual.

```text
/model claude-sonnet-5
```

2. **Al iniciar Claude Code:** ejecuta `claude --model <model-name>` para indicar un modelo. Útil para una sola sesión.

```text
claude --model claude-sonnet-5
```

3. **Configurar variables de entorno:** define modelos de distintos niveles según la complejidad de la tarea, y Claude Code elegirá automáticamente el adecuado. Se aplica de forma global.

```shellscript
export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-5-5"
export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-5"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-5-5"
```

Donde:

- `ANTHROPIC_DEFAULT_OPUS_MODEL`: para razonamiento complejo, diseño de arquitectura y otras tareas de alta dificultad.
- `ANTHROPIC_DEFAULT_SONNET_MODEL`: para escribir código, implementar funcionalidades y otras tareas del día a día.
- `ANTHROPIC_DEFAULT_HAIKU_MODEL`: para revisar sintaxis, buscar archivos y otras tareas sencillas.

4. **Configurar de forma permanente en settings.json:** escribe la configuración del modelo en el archivo de configuración de usuario de Claude Code (por ejemplo, `~/.claude/settings.json`, o `C:\Users\%USERNAME%\.claude\settings.json` en Windows) o en una configuración a nivel de proyecto, para dejarla fija a nivel de usuario o de proyecto.

<Warning>
  Si CC Switch muestra "Se detectó un conflicto con variables de entorno del sistema" (System environment variable conflict detected), resuelve primero `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` y `ANTHROPIC_MODEL`. Estas variables globales sobrescriben la configuración actual del proveedor, y un valor de marcador como `ANTHROPIC_AUTH_TOKEN=<HAROGO_API_KEY>` hará que la autenticación falle directamente. Cuando estés seguro de que ya no necesitas las variables globales, elimina las entradas en conflicto en CC Switch, o borra manualmente las variables de entorno del sistema o de usuario y reinicia tu terminal.
</Warning>
