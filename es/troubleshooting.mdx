title: "Solución de problemas"
---

## Clave API no válida

Comprueba en la [página de claves API](https://console.harogo.ai/keys) que la clave esté activa y que tu cliente use esa clave.

## Modelo no encontrado o denegado

Comprueba el ID exacto del modelo y el endpoint en la [tabla de compatibilidad](/es#model-compatibility).

## Se sigue usando el proveedor anterior

Comprueba el proveedor activo, la URL base y el modelo en el cliente. Si usas CC Switch, comprueba que Harogo esté seleccionado y que ninguna otra configuración lo sobrescriba.

## Cuota agotada

Comprueba qué límite has alcanzado en la [consola de Harogo](https://console.harogo.ai/plan).

Para seguir usando Harogo antes de que se restablezca el límite, cambia manualmente a una clave de saldo. Consulta [cuándo se restablecen los límites](/es/pricing#usage-limits).

## CC Switch {#cc-switch}

Descarga CC Switch desde la [página de versiones](https://github.com/farion1231/cc-switch/releases). Es opcional: puedes usarlo para cambiar de proveedor sin editar la configuración del cliente a mano.
