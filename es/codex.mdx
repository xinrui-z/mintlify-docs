<Note>
Esta página supone que Codex CLI ya está instalado.
</Note>

## 1. Obtén una clave de API

Abre la [consola de Harogo](https://console.harogo.ai/keys), crea una clave de API y cópiala. Trátala como una contraseña. No la subas a un repositorio ni la compartas. Elige una [clave de suscripción o de saldo](/es/pricing#billing-keys) según cómo quieras pagar.

## 2. Configura Harogo

Añade el proveedor Harogo a tu `~/.codex/config.toml` existente. Conserva tus proveedores y perfiles actuales; no reemplaces todo el archivo.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Establece `profile = "harogo"` solo si quieres que Harogo sea el perfil predeterminado. En tu `~/.codex/auth.json`, actualiza únicamente el valor de `OPENAI_API_KEY` y conserva las demás entradas.

Si usas [CC Switch](/es/troubleshooting#cc-switch), añade y activa allí el mismo proveedor en su lugar. No combines ambas configuraciones si no sabes cuál tiene prioridad.

Consulta la [tabla de compatibilidad de modelos](/es#model-compatibility) antes de elegir un ID de modelo.

## 3. Confirma la conexión

Inicia el cliente ya instalado desde el directorio de tu proyecto:

```shellscript
codex
```

Envía una solicitud mínima como `Reply with exactly: 2`. Comprueba la respuesta y el modelo activo, por ejemplo `gpt-6.2-sol`. Una respuesta normal por sí sola no confirma que Harogo esté activo.
