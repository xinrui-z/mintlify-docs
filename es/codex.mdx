<Note>
**Esta guía usa solo modelos GPT.** Codex puede ejecutar los modelos GPT (GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra) y los modelos sin restricción de cliente (GLM, Qwen, Kimi, MiniMax, DeepSeek). Los modelos Claude no están disponibles en Codex; consulta [Claude Code](/es/claude-code).
</Note>

## Instalación

### Descargar desde el sitio oficial (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Instalar desde la línea de comandos

```bash
npm install -g @openai/codex
```

## Configuración del entorno

### Configurar con el archivo de configuración

1. Edita tu archivo `~/.codex/config.toml` y añade lo siguiente:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Edita tu archivo `~/.codex/auth.json` y actualízalo así:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Usar Codex

### En la terminal

1. Abre una terminal, ve al directorio de tu proyecto y ejecuta el comando `codex`.

```bash
cd /path/to/your/project
codex
```

2. Configura los permisos según lo necesites.

<img
  alt="Configuración de permisos de aprobación al iniciar Codex"
  width="1212"
  height="814"

  lightAlt="Configuración de permisos de aprobación al iniciar Codex"
  darkAlt="Configuración de permisos de aprobación al iniciar Codex"

/>

3. Escribe un prompt en lenguaje natural. Si recibes una respuesta normal, la configuración se completó correctamente.
