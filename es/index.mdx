Harogo es una suscripción multimodelo creada para agentes de programación.

Una vez suscrito, puedes usar varios modelos de programación con una sola cuenta y una sola clave de API de Harogo. Todos los modelos comparten la misma cuota de suscripción, así que no necesitas registrarte, recargar saldo ni gestionar plataformas de modelos por separado.

## Primeros pasos

1. [Abrir la página de suscripción de Harogo](https://console.harogo.ai/plan)
2. [Crear y copiar una clave API en la consola](https://console.harogo.ai/keys)
3. Sigue la guía de tu cliente: [Claude Code](/es/claude-code) o [Codex](/es/codex).

Mantén tu clave de API en privado. No la subas a un repositorio público ni la compartas con nadie.

## Modelos compatibles {#model-compatibility}

Estos resultados corresponden al plan básico de Harogo. [Claude Code](/es/claude-code) usa `POST /v1/messages` y [Codex](/es/codex) usa `POST /v1/responses`.

| Qwen4 Max | `qwen4-max` | Razonamiento complejo, comprensión visual y llamadas a herramientas integradas | No disponible | Compatible |
| Kimi K3.1 Pro | `kimi-k3.1-pro` | Programación de larga duración, contexto de 1M, front-end y modelado 3D | No disponible | Compatible |

| DeepSeek V4 Pro | `deepseek-v4-pro` | Razonamiento y generación de código complejo | No disponible | Compatible |
| DeepSeek V4.1 Flash 1017 | `deepseek-v4.1-flash-1017` | Respuestas rápidas, llamadas de alta frecuencia, tareas por lotes | No disponible | Compatible |
