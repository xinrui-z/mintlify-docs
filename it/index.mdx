Harogo è un abbonamento multi-modello pensato per gli agenti di coding.

Una volta abbonato, puoi usare più modelli di coding con un unico account Harogo e un'unica chiave API. Tutti i modelli condividono la stessa quota di abbonamento, quindi non serve registrarsi, ricaricare il saldo o gestire piattaforme di modelli separate.

## Primi passi

1. [Apri la pagina degli abbonamenti Harogo](https://console.harogo.ai/plan)
2. [Crea e copia una chiave API nella console](https://console.harogo.ai/keys)
3. Segui la guida del tuo client: [Claude Code](/it/claude-code) o [Codex](/it/codex).

Custodisci la tua chiave API. Non includerla nei commit di un repository pubblico e non condividerla con nessuno.

## Modelli supportati {#model-compatibility}

Questi risultati si applicano al piano base di Harogo. [Claude Code](/it/claude-code) usa `POST /v1/messages`, mentre [Codex](/it/codex) usa `POST /v1/responses`.

| Modello | ID modello | Ideale per | Messages | Responses |
| --- | --- | --- | --- | --- |
| GLM-5.4 | `glm-5.4` | Task di lunga durata, codebase estese, coding per agenti | Non disponibile | Supportato |
| Qwen4 Max | `qwen4-max` | Ragionamento complesso, comprensione visiva e chiamate a strumenti integrate | Non disponibile | Supportato |
| Kimi K3.1 Pro | `kimi-k3.1-pro` | Coding di lunga durata, contesto da 1M, front-end e modellazione 3D | Non disponibile | Supportato |
| MiniMax M3 | `minimax-m3` | Coding ad alta frequenza, chiamate a strumenti, contesto lungo | Non disponibile | Supportato |
| DeepSeek V4 Pro | `deepseek-v4-pro` | Ragionamento e generazione di codice complessa | Non disponibile | Supportato |
| DeepSeek V4.1 Flash 1017 | `deepseek-v4.1-flash-1017` | Completamenti rapidi, chiamate ad alta frequenza, task in batch | Non disponibile | Supportato |
| Claude Opus 5.5 | `claude-opus-5-5` | Coding complesso per agenti e task di ingegneria difficili | Riservato a Claude Code | Non disponibile |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | Coding quotidiano e sviluppo generale | Riservato a Claude Code | Non disponibile |
| Claude Haiku 5.5 | `claude-haiku-5-5` | Risposte rapide, task leggeri, elaborazione in batch | Riservato a Claude Code | Non disponibile |
| GPT-6 Luna | `gpt-6-luna` | Coding ad alta frequenza e task leggeri | Non disponibile | Supportato |
| GPT-6.2 Sol | `gpt-6.2-sol` | Generazione di codice complessa, revisione e ragionamento | Non disponibile | Supportato |
| GPT-6.2 Astra | `gpt-6.2-astra` | Ragionamento di punta per i problemi di ingegneria più difficili | Non disponibile | Supportato |
| GPT-6.1 Terra | `gpt-6.1-terra` | Coding quotidiano per agenti e task generali | Non disponibile | Supportato |

I nomi e gli ID dei modelli qui sopra sono gli identificatori di instradamento usati internamente da Harogo. L'elenco dei modelli, le versioni e la disponibilità possono cambiare: verifica l'elenco attuale nella console.
