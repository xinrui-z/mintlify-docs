<Note>
**Questa guida usa solo modelli GPT.** Codex può eseguire i modelli GPT (GPT-6 Luna, GPT-6 Sol, GPT-6.1 Sol, GPT-6 Astra, GPT-6.1 Terra) e i modelli senza restrizioni di client (GLM, Qwen, Kimi, MiniMax, DeepSeek). I modelli Claude non sono disponibili in Codex — vedi [Claude Code](/it/claude-code).
</Note>

## Installazione

### Download dal sito ufficiale (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Installazione da riga di comando

```bash
npm install -g @openai/codex
```

## Configurazione delle variabili d'ambiente

### Configurazione tramite file di configurazione

1. Modifica il file `~/.codex/config.toml` e aggiungi quanto segue:

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Modifica il file `~/.codex/auth.json` come segue:

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Usare Codex

### Nel terminale

1. Apri un terminale, spostati nella directory del progetto, poi esegui il comando `codex`.

```bash
cd /path/to/your/project
codex
```

2. Imposta i permessi in base alle tue esigenze.

<img
  alt="Impostazione dei permessi di approvazione all'avvio di Codex"

3. Scrivi un prompt in linguaggio naturale: se ricevi una risposta normale, la configurazione è riuscita.
