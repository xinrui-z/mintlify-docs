<Note>
Questa pagina presuppone che Codex CLI sia già installato.
</Note>

## 1. Ottieni una chiave API

Apri la [console Harogo](https://console.harogo.ai/keys), crea una chiave API e copiala. Trattala come una password. Non inserirla in un repository e non condividerla. Scegli una [chiave di abbonamento o a saldo](/it/pricing#billing-keys) in base a come vuoi pagare.

## 2. Configura Harogo

Aggiungi il provider Harogo al tuo `~/.codex/config.toml` esistente. Mantieni provider e profili già presenti; non sostituire l'intero file.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Imposta `profile = "harogo"` solo se vuoi Harogo come profilo predefinito. Nel file esistente `~/.codex/auth.json`, aggiorna solo il valore di `OPENAI_API_KEY` e conserva tutte le altre voci.

Se usi [CC Switch](/it/troubleshooting#cc-switch), aggiungi e abilita invece lo stesso provider lì. Non combinare le configurazioni se non sai quale abbia la precedenza.

Consulta la [tabella di compatibilità dei modelli](/it#model-compatibility) prima di scegliere un ID modello.

## 3. Verifica la connessione

Dalla directory del progetto, avvia il client già installato:

```shellscript
codex
```

Invia una richiesta minima come `Reply with exactly: 2`. Controlla la risposta e il modello attivo, ad esempio `gpt-6.2-sol`. Una risposta normale da sola non conferma che Harogo sia attivo.
