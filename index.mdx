# Introduction

Harogo is a multi-model subscription service built for coding agents.

The discounted subscription price is \$4.90 for the first month, then \$9.90/month, with 100 discounted subscription slots currently available. Remaining slots and the actual billed price are shown on the subscription page.

Once subscribed, you can use multiple coding models through a single Harogo account and API key. All models share the same subscription quota, so there's no need to sign up for, fund, or manage separate model platforms.

# Why Harogo

Different models excel at different coding tasks. Using multiple model providers directly usually means juggling several accounts, API keys, balances, rate limits, and bills at once.

Harogo brings together a range of models well-suited to coding agents into a single service. You're free to switch between models based on the task, with everything billed against one shared subscription quota.

The current models fall roughly into these groups:

- **Large codebases and hard reasoning**: Kimi K3.1 Pro, Claude Opus 5.5, GPT-6.1 Sol, GPT-6 Astra
- **Everyday agentic coding, code generation, and debugging**: Qwen4 Max, GLM-5.3, Claude Sonnet 5.5, GPT-6.1 Terra, MiniMax M3, DeepSeek V4 Pro
- **High-frequency calls, fast responses, and cost-sensitive tasks**: DeepSeek V4.1 Flash 1017, Claude Haiku 5.5, GPT-6 Luna

These groups are only a guide for choosing a model. Actual results depend on the task, the context, and how you use tools.

# Getting started

1. Sign in to Harogo and subscribe.
2. Create and copy an API key in the console.
3. Use `https://api.harogo.ai` for [Claude Code](/claude-code), or `https://api.harogo.ai/v1` for [Codex](/codex) and [OpenCode](/untitled-page). Follow the guide for your client.
4. Paste in your API key.
5. Start using it.

Keep your API key safe. Don't commit it to a public repository or share it with anyone.

## Model Availability by Client

Some models are limited to a specific client. Others can be used anywhere.

<Note>
**GPT models** (GPT-6 Luna, GPT-6.1 Sol, GPT-6 Astra, GPT-6.1 Terra) can only be used in [Codex](/codex).

**Claude models** (Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5) can only be used in [Claude Code](/claude-code).

**All other models** (GLM, Qwen, Kimi, MiniMax, DeepSeek) have no client restriction and work in any supported client.
</Note>

## Usage and Limits

Harogo enforces the following usage limits:

- Daily limit: \$12
- Weekly limit: \$30
- Monthly limit: \$60

All three limits apply at the same time. Every model call draws from the shared subscription quota. Every model is capped at \$60.

Limits are defined in dollar amounts rather than a fixed request count. How many requests you actually get depends on the model you use — lower-priced models generally support more requests, while higher-priced models support fewer.

You can check your current usage and remaining quota in the [Harogo console](https://console.harogo.ai/plan).
