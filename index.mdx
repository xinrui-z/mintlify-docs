# Introduction

Harogo is a multi-model subscription service built for coding agents.

The discounted subscription price is \$4.9/month, with 100 discounted subscription slots currently available. Remaining slots and the actual billed price are shown on the subscription page.

Once subscribed, you can use multiple coding models through a single Harogo account and API key. All models share the same subscription quota, so there's no need to sign up for, fund, or manage separate model platforms.

# Why Harogo

Different models excel at different coding tasks. Using multiple model providers directly usually means juggling several accounts, API keys, balances, rate limits, and bills at once.

Harogo brings together a range of models well-suited to coding agents into a single service. You're free to switch between models based on the task, with everything billed against one shared subscription quota.

## Usage and Limits

Harogo enforces the following usage limits:

- Daily limit: \$12
- Weekly limit: \$30
- Monthly limit: \$60

All three limits apply at the same time. Every model call draws from the shared subscription quota, and some models also carry a lower per-model usage cap — see the pricing table below for details.

Limits are defined in dollar amounts rather than a fixed request count. How many requests you actually get depends on the model you use — lower-priced models generally support more requests, while higher-priced models support fewer.

You can check your current usage and remaining quota in the [Harogo console](https://console.harogo.ai/plan).
