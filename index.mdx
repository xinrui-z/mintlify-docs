Harogo is a multi-model subscription service built for coding agents.

Once subscribed, you can use multiple coding models through a single Harogo account and API key. All models share the same subscription quota, so there's no need to sign up for, fund, or manage separate model platforms.

## Getting started

1. [Open the Harogo subscription page](https://console.harogo.ai/plan)
2. [Create and copy an API key in the console](https://console.harogo.ai/keys)
3. Follow the guide for your client: [Claude Code](/claude-code) or [Codex](/codex).

Keep your API key safe. Don't commit it to a public repository or share it with anyone.

## Supported Models {#model-compatibility}

These results apply to the Harogo Basic plan. [Claude Code](/claude-code) uses `POST /v1/messages`. [Codex](/codex) uses `POST /v1/responses`.

| Kimi K3.1 Pro | `kimi-k3.1-pro` | Long-horizon coding, 1M context, front-end and 3D modeling | Not available | Supported |

| DeepSeek V4.1 Flash 1017 | `deepseek-v4.1-flash-1017` | Fast completions, high-frequency calls, and batch tasks | Not available | Supported |
| Claude Opus 5.5 | `claude-opus-5-5` | Complex agentic coding and high-difficulty engineering tasks | Restricted to Claude Code clients | Not available |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | Everyday coding and general development tasks | Restricted to Claude Code clients | Not available |
| Claude Haiku 5.5 | `claude-haiku-5-5` | Fast responses, lightweight tasks, and batch processing | Restricted to Claude Code clients | Not available |

| GPT-6.1 Terra | `gpt-6.1-terra` | Everyday agentic coding and general tasks | Not available | Supported |

The names and model IDs above are the routing identifiers Harogo uses internally. The model lineup, versions, and availability may change — check the console for the current list.
