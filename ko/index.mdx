Harogo는 코딩 에이전트를 위한 멀티 모델 구독 서비스입니다.

구독하면 하나의 Harogo 계정과 API 키로 여러 코딩 모델을 사용할 수 있습니다. 모든 모델이 동일한 구독 쿼터를 공유하므로 모델 플랫폼마다 따로 가입하고 충전하고 관리할 필요가 없습니다.

## 시작하기

1. [Harogo 구독 페이지 열기](https://console.harogo.ai/plan)
2. [콘솔에서 API 키 만들고 복사하기](https://console.harogo.ai/keys)
3. 사용 중인 클라이언트의 가이드([Claude Code](/ko/claude-code) 또는 [Codex](/ko/codex))에 따라 설정하세요.

API 키는 안전하게 보관하세요. 공개 저장소에 커밋하거나 다른 사람과 공유하지 마세요.

## 지원 모델 {#model-compatibility}

아래 결과는 Harogo 기본 요금제에 적용됩니다. [Claude Code](/ko/claude-code)는 `POST /v1/messages`를, [Codex](/ko/codex)는 `POST /v1/responses`를 사용합니다.

| GLM-5.4 | `glm-5.4` | 장기 실행 작업, 대규모 코드베이스, 에이전트 코딩 | 사용 불가 | 지원 |
| Qwen4 Max | `qwen4-max` | 복잡한 추론, 시각 이해, 내장 도구 호출 | 사용 불가 | 지원 |

| MiniMax M3 | `minimax-m3` | 고빈도 코딩, 도구 호출, 긴 컨텍스트 | 사용 불가 | 지원 |

| GPT-6.2 Astra | `gpt-6.2-astra` | 가장 어려운 엔지니어링 문제를 위한 플래그십 추론 | 사용 불가 | 지원 |
