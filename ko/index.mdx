# 소개

Harogo는 코딩 에이전트를 위한 멀티 모델 구독 서비스입니다.

할인 구독 가격은 첫 달 \$4.90, 이후 월 \$9.90이며, 현재 할인 구독 슬롯 100개를 이용할 수 있습니다. 잔여 슬롯 수와 정산 가격은 구독 페이지에 표시됩니다. 구독은 매월 자동으로 갱신되며 Stripe를 통해 카드로 결제됩니다. 첫 달 가격은 Harogo를 처음 구독하는 경우에만 적용됩니다. 콘솔의 **Plan** 페이지에서 언제든지 자동 갱신을 해지할 수 있으며, 이미 결제한 기간이 끝날 때까지 계속 이용할 수 있습니다.

구독하면 하나의 Harogo 계정과 API 키로 여러 코딩 모델을 사용할 수 있습니다. 모든 모델이 동일한 구독 쿼터를 공유하므로 모델 플랫폼마다 따로 가입하고 충전하고 관리할 필요가 없습니다.

# Harogo를 선택하는 이유

모델마다 강점을 보이는 코딩 작업이 다릅니다. 여러 모델 제공업체를 직접 이용하면 보통 여러 개의 계정, API 키, 잔액, 요청 한도, 청구서를 동시에 관리해야 합니다.

Harogo는 코딩 에이전트에 적합한 다양한 모델을 하나의 서비스로 모았습니다. 작업에 따라 모델을 자유롭게 전환할 수 있으며, 모든 사용량은 하나의 공유 구독 쿼터에서 차감됩니다.

현재 모델은 대략 다음과 같이 분류됩니다.

- **대규모 코드베이스와 고난도 추론**: Kimi K3.1 Pro, Claude Opus 5.5, GPT-6.2 Sol, GPT-6.2 Astra
- **일상적인 에이전트 코딩, 코드 생성, 디버깅**: Qwen4 Max, GLM-5.3, Claude Sonnet 5.5, GPT-6.1 Terra, MiniMax M3, DeepSeek V4 Pro
- **고빈도 호출, 빠른 응답, 비용에 민감한 작업**: DeepSeek V4.1 Flash 1017, Claude Haiku 5.5, GPT-6 Luna

이 분류는 모델을 선택할 때 참고용입니다. 실제 결과는 작업, 컨텍스트, 도구 사용 방식에 따라 달라집니다.

# 시작하기

1. Harogo에 로그인하고 구독합니다.
2. 콘솔에서 API 키를 생성하고 복사합니다.
3. [Claude Code](/ko/claude-code)는 `https://api.harogo.ai`를, [Codex](/ko/codex)와 [OpenCode](/ko/opencode)는 `https://api.harogo.ai/v1`을 사용합니다. 해당 클라이언트의 안내에 따라 설정하세요.
4. API 키를 붙여 넣습니다.
5. 사용을 시작합니다.

API 키는 안전하게 보관하세요. 공개 저장소에 커밋하거나 다른 사람과 공유하지 마세요.

## 클라이언트별 모델 사용 범위

일부 모델은 특정 클라이언트에서만 사용할 수 있으며, 나머지 모델은 제한이 없습니다.

<Note>
**GPT 시리즈**(GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra)는 [Codex](/ko/codex)에서만 사용할 수 있습니다.

**Claude 시리즈**(Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5)는 [Claude Code](/ko/claude-code)에서만 사용할 수 있습니다.

**그 외 모델**(GLM, Qwen, Kimi, MiniMax, DeepSeek)은 클라이언트 제한이 없으며 지원되는 모든 클라이언트에서 사용할 수 있습니다.
</Note>

## 사용량 및 한도

Harogo에는 다음과 같은 사용 한도가 적용됩니다.

- 일간 한도: \$12
- 주간 한도: \$30
- 월간 한도: \$60

세 가지 한도는 모두 동시에 적용됩니다. 모든 모델 호출은 공유 구독 쿼터에서 차감됩니다. 모델마다 사용 상한이 다릅니다. 상한이 \$60보다 낮은 모델은 공유 쿼터를 더 빨리 소진하고, \$60보다 높은 모델은 더 천천히 소진합니다. 모델별 상한은 [요금](/ko/pricing)에서 확인하세요.

한도는 고정된 요청 수가 아니라 USD 금액으로 설정됩니다. 실제로 확보되는 요청 수는 사용하는 모델에 따라 달라지며, 일반적으로 저렴한 모델일수록 더 많은 요청을, 비싼 모델일수록 더 적은 요청을 사용할 수 있습니다.

현재 사용량과 잔여 쿼터는 [Harogo 콘솔](https://console.harogo.ai/plan)에서 확인할 수 있습니다.

### 예상 요청량

아래 표는 일반적인 Harogo 사용 패턴을 기준으로 모델별 요청 수를 추정한 것입니다. 공유 쿼터는 일 / 주 / 월 기준 \$12 / \$30 / \$60이지만, 모델마다 사용 상한이 다르며 상한이 낮은 모델일수록 공유 쿼터를 더 빨리 소진합니다. 표의 상한은 해당 모델만 사용할 때 각 기간에 쓸 수 있는 양입니다.

<Note>
**사용 상한은 모델별 별도 한도가 아닙니다.** 모든 모델은 일 \$12, 주 \$30, 월 \$60의 하나의 공유 쿼터에서 차감됩니다. 모델별 사용 상한은 해당 모델만 사용할 때 쓸 수 있는 양을 보여줄 뿐이며, 상한은 합산되지 않고 같은 기간에 모든 모델의 상한을 다 쓸 수는 없습니다. 예를 들어 Kimi K3.1 Pro의 월 상한 \$15를 모두 사용하면 그달의 공유 쿼터가 전부 소진되어 다른 모델은 사용할 수 없습니다.
</Note>

각 행은 해당 기간의 쿼터를 대부분 그 모델 하나에 사용한다고 가정한 값입니다. 여러 모델을 함께 사용하면 동일한 공유 쿼터에서 함께 차감되므로, 표의 요청 수를 행끼리 단순히 더할 수는 없습니다.

실제 요청량은 컨텍스트 길이, 캐시 적중률, 추론 강도, 출력 길이 등의 요인에 따라 달라집니다. 또한 코딩 에이전트가 작업 하나를 완료할 때는 보통 여러 번의 모델 요청이 발생하므로, 요청 1건이 코딩 작업 1건의 완료를 의미하지는 않습니다.

이 수치는 일반적인 사용량을 추정하기 위한 것이며 고정된 요청 수를 보장하지 않습니다. 쿼터 상한과 예상 요청량은 서비스 변경에 따라 달라질 수 있으니 Harogo 콘솔과 이 페이지에서 최신 정보를 확인하세요.
