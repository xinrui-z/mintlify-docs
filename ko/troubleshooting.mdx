## API 키가 유효하지 않음

[API 키 페이지](https://console.harogo.ai/keys)에서 키가 활성 상태인지, 클라이언트가 해당 키를 쓰는지 확인하세요.

## 모델을 찾을 수 없거나 접근이 거부됨

[모델 호환성 표](/ko#model-compatibility)에서 정확한 모델 ID와 엔드포인트를 확인하세요.

## 이전 제공업체를 계속 사용함

클라이언트에서 활성 제공업체, 기본 URL, 모델을 확인하세요. CC Switch를 쓴다면 Harogo가 선택되어 있고 다른 설정이 이를 덮어쓰지 않는지 확인하세요.

## 쿼터 한도에 도달함

[Harogo 콘솔](https://console.harogo.ai/plan)에서 어떤 한도에 도달했는지 확인하세요.

한도가 초기화되기 전에 Harogo를 계속 사용하려면 잔액 결제용 키로 직접 전환하세요. [한도 초기화 시점](/ko/pricing#usage-limits)을 확인하세요.

## CC Switch {#cc-switch}

CC Switch는 [릴리스 페이지](https://github.com/farion1231/cc-switch/releases)에서 다운로드할 수 있습니다. 선택 사항이며 클라이언트 설정을 직접 편집하지 않고 제공업체를 전환할 때 사용합니다.
