<Note>
**이 가이드는 GPT 시리즈만 사용합니다.** Codex에서는 GPT 시리즈(GPT-6 Luna, GPT-6 Sol, GPT-6.1 Sol, GPT-6 Astra, GPT-6.1 Terra)와 제한이 없는 모델(GLM, Qwen, Kimi, MiniMax, DeepSeek)을 실행할 수 있습니다. Claude 시리즈는 Codex에서 사용할 수 없습니다. [Claude Code](/ko/claude-code)를 참고하세요.
</Note>

## 설치

### 공식 사이트에서 다운로드(macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### 명령줄로 설치

```bash
npm install -g @openai/codex
```

## 환경 변수 설정

### 설정 파일로 설정하기

1. `~/.codex/config.toml` 파일을 편집해 다음 내용을 추가합니다.

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. `~/.codex/auth.json` 파일을 편집해 다음과 같이 수정합니다.

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Codex 사용하기

### 터미널에서 사용하기

1. 터미널을 열고 프로젝트 디렉터리로 이동한 뒤 `codex` 명령을 실행합니다.

```bash
cd /path/to/your/project
codex
```

2. 필요에 따라 권한을 설정합니다.

<img
  alt="Codex 시작 시 승인 권한을 설정하는 화면"
  width="1212"
  height="814"
  data-path="public/cn/codex-5.png"

  src="/images/iShot_2026-08-07_17.31.13.png"
/>

3. 자연어로 프롬프트를 입력하세요. 정상적인 응답이 돌아오면 설정이 완료된 것입니다.
