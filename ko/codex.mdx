<Note>
이 페이지는 Codex CLI가 이미 설치되어 있다고 가정합니다.
</Note>

## 1. API 키 받기

[Harogo 콘솔](https://console.harogo.ai/keys)을 열고 API 키를 생성한 뒤 복사합니다. 키는 비밀번호처럼 관리하세요. 저장소에 커밋하거나 공유하지 마세요. 결제 방식에 따라 [구독용 키 또는 잔액 결제용 키](/ko/pricing#billing-keys)를 선택하세요.

## 2. Harogo 구성

기존 `~/.codex/config.toml`에 Harogo Provider를 추가합니다. 기존 Provider와 Profile을 보존하고 파일 전체를 교체하지 마세요.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Harogo를 기본 Profile로 사용할 때만 `profile = "harogo"`를 설정하세요. 기존 `~/.codex/auth.json`에서는 `OPENAI_API_KEY` 값만 Harogo API 키로 업데이트하고 다른 항목은 보존하세요.

[CC Switch](/ko/troubleshooting#cc-switch)를 사용한다면 대신 그곳에 같은 Provider를 추가하고 활성화하세요. 우선순위를 모른다면 두 구성을 동시에 사용하지 마세요.

모델 ID를 선택하기 전에 [모델 호환성 표](/ko#model-compatibility)를 확인하세요.

## 3. 연결 확인

프로젝트 디렉터리에서 이미 설치된 클라이언트를 시작합니다.

```shellscript
codex
```

`Reply with exactly: 2` 같은 간단한 요청을 보냅니다. 응답이 반환되고 활성 모델이 구성한 Harogo 모델(예: `gpt-6.2-sol`)인지 확인하세요. 정상 응답만으로는 Harogo가 실제로 활성화되었다고 볼 수 없습니다.
