설치하기 전에 시스템이 다음 요구 사항을 충족하는지 확인하세요.

- **Node.js ≥ 18.0.0**
- 플랫폼에 맞는 패키지 관리자(선택 사항):
  - macOS / Linux: `brew`
  - Arch Linux: `paru`
  - Windows: `choco`, `winget` 또는 `scoop`

## 1. OpenCode 설치

시스템과 사용하는 도구에 맞는 설치 방법을 선택하세요.

### 1. Node.js로 설치

```text
# curl 스크립트로 빠르게 설치
curl -fsSL https://opencode.ai/install | bash

# NPM 사용
npm install -g opencode-ai

# Bun 사용
bun install -g opencode-ai

# PNPM 사용
pnpm install -g opencode-ai

# Yarn 사용
yarn global add opencode-ai
```

---

### 2. Homebrew 사용(macOS / Linux)

```text
brew install sst/tap/opencode
```

---

### 3. Paru 사용(Arch Linux)

```text
paru -S opencode-bin
```

---

### 4. Windows에서 설치

Windows 사용자는 다음 방법 중 하나로 OpenCode를 설치할 수 있습니다.

```text
# Chocolatey
choco install opencode

# WinGet
winget install opencode

# Scoop
scoop bucket add extras
scoop install extras/opencode

# 또는 NPM으로 설치(Node.js 필요) — 참고: 관리자 권한이 필요합니다
npm install -g opencode-ai
```

---
