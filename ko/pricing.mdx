## 참고 사항

- 월간 한도는 모델마다 다릅니다. 한도가 낮은 모델은 공유 쿼터를 더 빨리, 한도가 높은 모델은 더 천천히 소진합니다.
- 사용 상한은 모델별 별도 한도가 아닙니다. 모든 모델이 하나의 쿼터를 공유하며, 각 상한은 해당 모델만 사용할 때의 양을 나타낼 뿐 합산되지 않습니다.
- 입력 구간이 표시된 모델은 구간별 요금이 적용됩니다. 단일 요청의 총 입력(입력 + 캐시 읽기 + 캐시 쓰기)이 임계값을 넘으면 요청 전체가 상위 구간 요금으로 과금됩니다.
- API 사용 금액은 표의 가격으로 계산합니다. 모델별 쿼터 배율에 따라 공유 구독 쿼터에서 차감되는 양이 달라집니다.
- 구독 할당량이 아닌 계정 잔액으로 결제하는 경우, 위 표의 가격이 그대로 전액 과금됩니다.

가격과 한도는 모델 구성에 따라 변경될 수 있습니다. [Harogo 콘솔](https://console.harogo.ai/plan)과 이 페이지가 최신 정보입니다.

## 사용량 및 한도 {#usage-limits}

Harogo에는 다음과 같은 사용 한도가 적용됩니다.

- 일간 한도: \$12 (매일 **16:00 UTC**에 초기화)
- 주간 한도: \$30 (구독을 처음 사용한 시점부터 7일마다 초기화)
- 월간 한도: \$60 (구독을 처음 사용한 시점부터 30일마다 초기화)

세 가지 한도는 모두 동시에 적용됩니다. 모델마다 사용 상한이 다릅니다. 상한이 \$60보다 낮은 모델은 공유 쿼터를 더 빨리 소진하고, \$60보다 높은 모델은 더 천천히 소진합니다. 모델별 상한은 [요금](#token-prices)에서 확인하세요.

한도는 고정된 요청 수가 아니라 USD 금액으로 설정됩니다. 실제로 확보되는 요청 수는 사용하는 모델에 따라 달라지며, 일반적으로 저렴한 모델일수록 더 많은 요청을, 비싼 모델일수록 더 적은 요청을 사용할 수 있습니다.

현재 사용량과 잔여 쿼터는 [Harogo 콘솔](https://console.harogo.ai/plan)에서 확인할 수 있습니다.

### 구독용 API 키와 잔액 결제용 API 키 {#billing-keys}

[API 키 페이지](https://console.harogo.ai/keys)에서 키를 각각 생성하세요. 구독용 키는 플랜 할당량을 사용하고, 잔액 결제용 키는 계정 잔액에서 결제합니다. 두 사용량은 별도로 집계됩니다. 구독 할당량을 모두 사용해도 Harogo가 잔액에서 자동으로 차감하지 않습니다.
