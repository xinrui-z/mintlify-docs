<Note>
**Ce guide utilise uniquement les modèles GPT.** Codex peut exécuter les modèles GPT (GPT-6 Luna, GPT-6 Sol, GPT-6.1 Sol, GPT-6 Astra, GPT-6.1 Terra) ainsi que les modèles sans restriction de client (GLM, Qwen, Kimi, MiniMax, DeepSeek). Les modèles Claude ne sont pas disponibles dans Codex — voir [Claude Code](/fr/claude-code).
</Note>

## Installation

### Télécharger depuis le site officiel (macOS)

[https://openai.com/codex/](https://openai.com/codex/)

### Installer en ligne de commande

```bash
npm install -g @openai/codex
```

## Configuration des variables d'environnement

### Configurer via le fichier de configuration

1. Modifiez votre fichier `~/.codex/config.toml` et ajoutez le contenu suivant :

```toml
profile = "harogo"

[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
personality = "pragmatic"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.1-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

2. Modifiez votre fichier `~/.codex/auth.json` comme suit :

```json
{
  "OPENAI_API_KEY": "HAROGO_API_KEY"
}
```

## Utiliser Codex

### Dans le terminal

1. Ouvrez un terminal, placez-vous dans le répertoire de votre projet, puis exécutez la commande `codex`.

```bash
cd /path/to/your/project
codex
```

2. Définissez les autorisations selon vos besoins.

<img
  alt="Définition des autorisations d'approbation au démarrage de Codex"
  width="1212"
  height="814"
  data-path="public/cn/codex-5.png"
  lightAlt="Définition des autorisations d'approbation au démarrage de Codex"
  darkAlt="Définition des autorisations d'approbation au démarrage de Codex"
  src="/images/iShot_2026-08-07_17.31.13.png"
/>

3. Saisissez une instruction en langage naturel : si vous obtenez une réponse normale, la configuration a réussi.
