<Note>
Cette page suppose que Codex CLI est déjà installé.
</Note>

## 1. Obtenir une clé API

Ouvrez la [console Harogo](https://console.harogo.ai/keys), créez une clé API et copiez-la. Traitez-la comme un mot de passe. Ne la publiez pas dans un dépôt et ne la partagez pas. Choisissez une [clé d’abonnement ou de solde](/fr/pricing#billing-keys) selon le mode de paiement souhaité.

## 2. Configurer Harogo

Ajoutez le fournisseur Harogo à votre `~/.codex/config.toml` existant. Gardez vos fournisseurs et profils actuels ; ne remplacez pas tout le fichier.

```toml
[model_providers.harogo]
name = "harogo"
base_url = "https://api.harogo.ai/v1"
wire_api = "responses"

[profiles.harogo]
model = "gpt-6.2-sol"
model_provider = "harogo"
model_reasoning_effort = "high"
```

Définissez `profile = "harogo"` uniquement si Harogo doit être le profil par défaut. Dans votre `~/.codex/auth.json`, mettez à jour uniquement la valeur de `OPENAI_API_KEY` et gardez les autres entrées.

Avec [CC Switch](/fr/troubleshooting#cc-switch), ajoutez et activez plutôt le même fournisseur dans cet outil. Ne combinez pas les deux configurations sans connaître leur priorité.

Consultez le [tableau de compatibilité des modèles](/fr#model-compatibility) avant de choisir un ID de modèle.

## 3. Vérifier la connexion

Depuis le répertoire de votre projet, démarrez le client déjà installé :

```shellscript
codex
```

Envoyez une requête minimale comme `Reply with exactly: 2`. Vérifiez la réponse et le modèle actif, par exemple `gpt-6.2-sol`. Une réponse normale ne suffit pas à confirmer que Harogo est actif.
