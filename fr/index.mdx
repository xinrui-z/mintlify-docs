# Présentation

Harogo est un abonnement multi-modèles conçu pour les agents de codage.

Le prix d'abonnement à tarif réduit est de \$4.90 le premier mois, puis de \$9.90/mois, avec 100 places d'abonnement à tarif réduit actuellement disponibles. Le nombre de places restantes et le prix de règlement sont indiqués sur la page d'abonnement.

Une fois abonné, vous pouvez utiliser plusieurs modèles de codage avec un seul compte Harogo et une seule clé API. Tous les modèles partagent le même quota d'abonnement : inutile de vous inscrire, de recharger un solde ou de gérer des plateformes de modèles séparées.

# Pourquoi Harogo

Chaque modèle excelle dans des tâches de codage différentes. Utiliser directement plusieurs fournisseurs de modèles signifie généralement gérer à la fois plusieurs comptes, clés API, soldes, limites de débit et factures.

Harogo réunit en un seul service un ensemble de modèles bien adaptés aux agents de codage. Vous changez librement de modèle selon la tâche, et toute l'utilisation est décomptée d'un seul quota d'abonnement partagé.

Les modèles actuels se répartissent globalement en plusieurs groupes :

- **Grandes bases de code et raisonnement complexe** : Kimi K3.1 Pro, Claude Opus 5.5, GPT-6.2 Sol, GPT-6.2 Astra
- **Codage d'agent au quotidien, génération de code et débogage** : Qwen4 Max, GLM-5.3, Claude Sonnet 5.5, GPT-6.1 Terra, MiniMax M3, DeepSeek V4 Pro
- **Appels haute fréquence, réponses rapides et tâches sensibles au coût** : DeepSeek V4.1 Flash 1017, Claude Haiku 5.5, GPT-6 Luna

Ces groupes servent uniquement de repère pour choisir un modèle. Les résultats réels dépendent de la tâche, du contexte et de la manière dont vous utilisez les outils.

# Prise en main

1. Connectez-vous à Harogo et abonnez-vous.
2. Créez et copiez une clé API dans la console.
3. Utilisez `https://api.harogo.ai` pour [Claude Code](/fr/claude-code), ou `https://api.harogo.ai/v1` pour [Codex](/fr/codex) et [OpenCode](/fr/opencode). Suivez le guide de votre client.
4. Collez votre clé API.
5. Commencez à l'utiliser.

Gardez votre clé API en lieu sûr. Ne la publiez pas dans un dépôt public et ne la partagez avec personne.

## Disponibilité des modèles par client

Certains modèles sont réservés à un client précis. Les autres fonctionnent partout.

<Note>
**Modèles GPT** (GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra) : uniquement disponibles dans [Codex](/fr/codex).

**Modèles Claude** (Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5) : uniquement disponibles dans [Claude Code](/fr/claude-code).

**Tous les autres modèles** (GLM, Qwen, Kimi, MiniMax, DeepSeek) n'ont aucune restriction de client et fonctionnent dans tout client pris en charge.
</Note>

## Utilisation et limites

Harogo applique les limites d'utilisation suivantes :

- Limite quotidienne : \$12
- Limite hebdomadaire : \$30
- Limite mensuelle : \$60

Les trois limites s'appliquent en même temps. Chaque appel de modèle puise dans le quota d'abonnement partagé. Chaque modèle a son propre plafond d'utilisation : les modèles plafonnés sous \$60 consomment le quota partagé plus vite, ceux plafonnés au-dessus de \$60 plus lentement. Le plafond de chaque modèle figure sur la page [Tarifs](/fr/pricing).

Les limites sont exprimées en dollars plutôt qu'en nombre fixe de requêtes. Le nombre de requêtes dont vous disposez réellement dépend du modèle utilisé : les modèles moins chers permettent généralement plus de requêtes, les modèles plus chers moins.

Vous pouvez consulter votre utilisation actuelle et votre quota restant dans la [console Harogo](https://console.harogo.ai/plan).

Le plafond de chaque modèle indique seulement ce que vous pouvez utiliser si vous n'utilisez que ce modèle : les plafonds ne s'additionnent pas, et vous ne pouvez pas utiliser le plafond complet de chaque modèle dans la même fenêtre.
