Harogo est un abonnement multi-modèles conçu pour les agents de codage.

Une fois abonné, vous pouvez utiliser plusieurs modèles de codage avec un seul compte Harogo et une seule clé API. Tous les modèles partagent le même quota d'abonnement : inutile de vous inscrire, de recharger un solde ou de gérer des plateformes de modèles séparées.

## Premiers pas

1. [Ouvrir la page d’abonnement Harogo](https://console.harogo.ai/plan)
2. [Créer et copier une clé API dans la console](https://console.harogo.ai/keys)
3. Suivez le guide de votre client : [Claude Code](/fr/claude-code) ou [Codex](/fr/codex).

Gardez votre clé API en lieu sûr. Ne la publiez pas dans un dépôt public et ne la partagez avec personne.
