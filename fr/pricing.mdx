## Remarques

- Le plafond mensuel varie selon le modèle. Les modèles au plafond plus bas consomment le quota partagé plus vite ; ceux au plafond plus élevé, plus lentement.
- Les plafonds d'utilisation ne sont pas des enveloppes séparées : tous les modèles partagent un quota, et chaque plafond indique seulement ce que ce modèle seul peut utiliser. Les plafonds ne s'additionnent pas.
- Les modèles avec une plage d'entrée sont facturés par paliers : lorsque l'entrée totale d'une requête (entrée + lectures du cache + écritures du cache) dépasse le seuil, toute la requête est facturée au palier supérieur.
- L’utilisation de l’API est calculée aux prix du tableau. Le multiplicateur du modèle détermine la quantité prélevée sur le quota partagé de l’abonnement.
- Si vous payez avec le solde de votre compte plutôt qu'avec le quota d'abonnement, les prix complets du tableau s'appliquent.

Les prix et les plafonds peuvent évoluer avec la gamme de modèles. La [console Harogo](https://console.harogo.ai/plan) et cette page font foi.

## Utilisation et limites {#usage-limits}

Harogo applique les limites d'utilisation suivantes :

- Limite quotidienne : \$12 (réinitialisation quotidienne à **16:00 UTC**)
- Limite hebdomadaire : \$30 (réinitialisation tous les 7 jours à compter de la première utilisation de l’abonnement)
- Limite mensuelle : \$60 (réinitialisation tous les 30 jours à compter de la première utilisation de l’abonnement)

Les trois limites s'appliquent en même temps. Chaque modèle a son propre plafond d'utilisation : les modèles plafonnés sous \$60 consomment le quota partagé plus vite, ceux plafonnés au-dessus de \$60 plus lentement. Le plafond de chaque modèle figure sur la page [Tarifs](#token-prices).

Les limites sont exprimées en dollars plutôt qu'en nombre fixe de requêtes. Le nombre de requêtes dont vous disposez réellement dépend du modèle utilisé : les modèles moins chers permettent généralement plus de requêtes, les modèles plus chers moins.

Vous pouvez consulter votre utilisation actuelle et votre quota restant dans la [console Harogo](https://console.harogo.ai/plan).

### Clés API pour l’abonnement et le solde {#billing-keys}

Créez deux clés distinctes sur la [page des clés API](https://console.harogo.ai/keys) : une clé d’abonnement pour utiliser le quota du forfait et une clé de solde pour payer avec le solde du compte. Les consommations sont comptabilisées séparément. Si le quota d’abonnement est épuisé, Harogo ne débite pas automatiquement votre solde.
