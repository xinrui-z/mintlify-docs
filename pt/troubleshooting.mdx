---
title: "Solução de problemas"
---

## Chave de API inválida

Verifique na [página de chaves de API](https://console.harogo.ai/keys) se a chave está ativa e se o cliente usa essa chave.

## Modelo não encontrado ou não permitido

Confira o ID exato do modelo e o endpoint na [tabela de compatibilidade](/pt#model-compatibility).

## O provedor anterior ainda está em uso

Confira o provedor ativo, a URL base e o modelo no cliente. Se usar CC Switch, confirme que Harogo está selecionado e que outras configurações não o substituem.

## Limite atingido

Veja qual limite de uso foi atingido no [console do Harogo](https://console.harogo.ai/plan).

Para continuar usando a Harogo antes que o limite seja redefinido, mude manualmente para uma chave de saldo. Consulte [quando os limites são redefinidos](/pt/pricing#usage-limits).

## CC Switch {#cc-switch}

Baixe o CC Switch na [página de versões](https://github.com/farion1231/cc-switch/releases). É opcional e permite trocar de provedor sem editar manualmente a configuração do cliente.
