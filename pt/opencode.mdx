Antes de instalar, verifique se o seu sistema atende aos seguintes requisitos:

- **Node.js ≥ 18.0.0**
- Um gerenciador de pacotes para a sua plataforma (opcional):
  - macOS / Linux: `brew`
  - Arch Linux: `paru`
  - Windows: `choco`, `winget` ou `scoop`

## 1. Instalar o OpenCode

Escolha o método de instalação mais adequado ao seu sistema e às suas ferramentas.

### 1. Instalar via Node.js

```text
# Instalação rápida via script curl
curl -fsSL https://opencode.ai/install | bash

# Usando NPM
npm install -g opencode-ai

# Usando Bun
bun install -g opencode-ai

# Usando PNPM
pnpm install -g opencode-ai

# Usando Yarn
yarn global add opencode-ai
```

---

### 2. Usando Homebrew (macOS / Linux)

```text
brew install sst/tap/opencode
```

---

### 3. Usando Paru (Arch Linux)

```text
paru -S opencode-bin
```

---

### 4. Instalação no Windows

No Windows, você pode instalar o OpenCode com qualquer uma das opções a seguir:

```text
# Chocolatey
choco install opencode

# WinGet
winget install opencode

# Scoop
scoop bucket add extras
scoop install extras/opencode

# Ou via NPM (requer Node.js); observação: requer privilégios de administrador
npm install -g opencode-ai
```
