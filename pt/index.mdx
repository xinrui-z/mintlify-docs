# Introdução

Harogo é uma assinatura multimodelo criada para agentes de programação.

O preço com desconto é de \$4.90 no primeiro mês e depois \$9.90/mês, com 100 vagas de assinatura com desconto disponíveis no momento. As vagas restantes e o preço final cobrado são exibidos na página de assinatura.

Depois de assinar, você pode usar vários modelos de programação com uma única conta e uma única chave de API da Harogo. Todos os modelos compartilham a mesma cota de assinatura, então não é preciso se cadastrar, recarregar saldo nem gerenciar plataformas de modelos separadas.

# Por que Harogo

Modelos diferentes se destacam em tarefas de programação diferentes. Usar vários provedores de modelos diretamente costuma significar gerenciar várias contas, chaves de API, saldos, limites de taxa e faturas ao mesmo tempo.

A Harogo reúne em um único serviço uma variedade de modelos adequados para agentes de programação. Você pode trocar de modelo livremente conforme a tarefa, e tudo é descontado de uma única cota de assinatura compartilhada.

Os modelos atuais se dividem, de forma geral, nestes grupos:

- **Bases de código grandes e raciocínio difícil**: Kimi K3.1 Pro, Claude Opus 5.5, GPT-6.2 Sol, GPT-6.2 Astra
- **Programação de agentes, geração de código e depuração no dia a dia**: Qwen4 Max, GLM-5.3, Claude Sonnet 5.5, GPT-6.1 Terra, MiniMax M3, DeepSeek V4 Pro
- **Chamadas de alta frequência, respostas rápidas e tarefas sensíveis a custo**: DeepSeek V4.1 Flash 1017, Claude Haiku 5.5, GPT-6 Luna

Esses grupos servem apenas de referência na hora de escolher um modelo. Os resultados reais dependem da tarefa, do contexto e de como você usa as ferramentas.

# Primeiros passos

1. Entre na Harogo e assine.
2. Crie e copie uma chave de API no console.
3. Use `https://api.harogo.ai` para [Claude Code](/pt/claude-code) ou `https://api.harogo.ai/v1` para [Codex](/pt/codex) e [OpenCode](/pt/opencode). Siga o guia do seu cliente.
4. Cole sua chave de API.
5. Comece a usar.

Mantenha sua chave de API privada. Não a envie para um repositório público nem a compartilhe com ninguém.

## Disponibilidade de modelos por cliente

Alguns modelos são restritos a um cliente específico. Os demais podem ser usados em qualquer um.

<Note>
**Modelos GPT** (GPT-6 Luna, GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra) só estão disponíveis no [Codex](/pt/codex).

**Modelos Claude** (Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5) só estão disponíveis no [Claude Code](/pt/claude-code).

**Todos os outros modelos** (GLM, Qwen, Kimi, MiniMax, DeepSeek) não têm restrição de cliente e funcionam em qualquer cliente compatível.
</Note>

## Uso e limites

A Harogo aplica os seguintes limites de uso:

- Limite diário: \$12
- Limite semanal: \$30
- Limite mensal: \$60

Os três limites se aplicam ao mesmo tempo. Cada chamada de modelo consome a cota de assinatura compartilhada. Cada modelo tem seu próprio limite de uso: modelos com limite abaixo de \$60 consomem a cota compartilhada mais rápido, e modelos com limite acima de \$60, mais devagar. Veja o limite de cada modelo em [Preços](/pt/pricing).

Os limites são definidos em valores em dólar, não em um número fixo de solicitações. Quantas solicitações você realmente recebe depende do modelo usado: modelos mais baratos geralmente permitem mais solicitações, e modelos mais caros, menos.

Você pode consultar o uso atual e a cota restante no [console da Harogo](https://console.harogo.ai/plan).

A cota compartilhada é de \$12 / \$30 / \$60 por dia / semana / mês, mas cada modelo tem seu próprio limite de uso: um modelo com limite menor consome a cota compartilhada mais rápido. O limite indicado é quanto esse modelo sozinho pode usar em cada janela.

<Note>
**Os limites de uso não são cotas separadas.** Todos os modelos consomem uma única cota compartilhada de \$12 por dia, \$30 por semana e \$60 por mês. O limite de cada modelo mostra apenas quanto você pode usar se usar somente esse modelo — os limites não se somam e não é possível usar o limite completo de todos os modelos na mesma janela. Por exemplo, esgotar o limite mensal de \$15 do Kimi K3.1 Pro consome toda a cota compartilhada do mês e não sobra nada para outros modelos.
</Note>

Cada linha supõe que a cota dessa janela de tempo é gasta principalmente nesse único modelo. Ao combinar modelos, todos consomem a mesma cota compartilhada, então os números de solicitações da tabela não podem ser simplesmente somados entre as linhas.

O volume real de solicitações é afetado por fatores como tamanho do contexto, taxa de acerto de cache, esforço de raciocínio e tamanho da saída. Além disso, um agente de programação normalmente faz várias solicitações ao modelo para concluir uma única tarefa, então uma solicitação não equivale a uma tarefa de programação completa.
